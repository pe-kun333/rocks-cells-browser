# Rocks-cells Browser

六角形の縦タブとハニカム盤面を持つ Windows ブラウザ。任意の機能として、外にいる **Grok Bot**（手元の、`grokbot://` のリンクを受け取るボットのアプリ。このリポジトリには含まれない）への窓口「ボットのセル」と「右下の Grok Bot」がある（既定ではオフ。冒頭の注記）。

- C++（Win32 + WebView2）：ウィンドウ、ページ表示、タブの作成・休眠からの起床・切り替え、ファイル保存、Grok Bot アプリを開く（URL はここで組み立てる）など「手足」の部分
- TypeScript：ハニカム UI、タブの配置・番号、拡大表示などのパネル、AI の相棒、ボットのセルの台帳など「頭と顔」の部分
- データは **`%LOCALAPPDATA%\RocksCellsBrowser\`** に置く（タブ・Cookie・メモ・会話・API キー）。窓の題名は「Rocks-cells Browser」

## 主な機能

- 六角形の縦タブとハニカムの盤面（小さい表示・大きい表示）、シートとシートへの入口（盤面の右クリックで、登録したシート・シートのセット・その他のシートへ移れる）、タブの見た目（画像・コメント）
- 自動休眠（一時停止 → 休眠）と、保存・復元（前回のタブを同じ場所・同じ番号で）
- メモのセル・六角形スクショ・コメントのスレッド・セルの範囲コピーとセット（六角メモとやりとり）
- **メモの分割**：メモのセルをダブルクリックすると、ページの下にそのメモを書く区画が開く（本文・コメントのカード・引用・画像・一覧）。詳しくは下の「メモの分割（中央を上下に分けて書く）」
- 六角で読む（ページの本文・YouTube・ラジオや自分のファイル）、順路、単語帳と復習（盤面のセル・画像とつなぐ、月の窓に映す）、リマインダー（自分で置く・繰り返し・サイトや起動をきっかけに）
- AI の相棒（Claude・ミツ・フェイブル・ソネット三人組・ハイク組と先生）：道具・記憶・情報収集・フェイブルレター・月の窓
- 右サイドバー：メモの区画・データ置き場・タグごとの一覧などのパネル。見出しの ▾ でたためて、右クリックで上のタグ（6つまで）に登録できる
- **アプリのセル**：盤面に Windows のアプリ（メモ帳や、スタートメニューの電卓・設定などのストアアプリ）を登録する。ダブルクリックで、その窓を中央の区画に合わせ、最前面で追従させる。詳しくは下の「アプリのセル」
- **ボットのセル**（任意のボット連携）：盤面から Grok Bot アプリのそのボットのチャットを開く。頼む文をコピーしてアプリを開く・アプリでコピーした返事をメモにする。ページやアドレス欄からは grokbot:// を開かない
- **右下の Grok Bot**（任意のボット連携）：右サイドバーの相棒の並びのすぐ下の六角形の輪（巣）に、Grok Bot を6体まで置く。席を押すと選び、ダブルクリックでアプリのチャット。頼むときは依頼の小窓（下の「右下の Grok Bot」）。5つのグループに役を割り当てて頼むこともできる（下の「Grok Bot のグループ」）
- **ボットの返事を受け取る**（任意のボット連携・第2段）：頼んだことの返事を中継から受け取り、依頼と合うか確かめて、右のボットの欄とボットのセルの顔に出す
- **撮影**：右サイドバーの「撮影」で、見えているページや窓を残す。ページの画像や、盤面・下の区画の画像も、右クリックで送って大きく開ける。盤面のシート「撮ったもの」で見返す。詳しくは下の「撮影」
- **見た目のテーマ**：左の表示のバーの ◐ で、13 のテーマ（明るい 8・中間と暗い 5）から選ぶ。自動（Windows の明暗に合わせる）か、いつも同じテーマ。窓の題名バーと枠も同じ色。詳しくは下の「見た目（テーマ）」

### 撮影
右サイドバーの区画「撮影」に、見ているページや窓の画像を残します。盤面のシート「撮ったもの」は、残したものを六角形で見返す場所です。盤面に新しく撮るボタンはありません。

| 操作 | 内容 |
|---|---|
| 「▣ 中央を撮る」 | 中央に見えているページを1枚残す。Ctrl+Shift+Y も同じ |
| そのボタンの右クリック「中央の見えている所」 | 同じ範囲を1枚残す。ページの右クリックにも同じ名前がある |
| 右クリック「中央を録画」 | 同じ範囲を mp4 にする。ページの右クリック「中央を録画」も同じ。止めるまで、または2分・80MB |
| 右クリック「ブラウザの窓全体」 | ブラウザの窓を1枚残す |
| 右クリック「この画面のデスクトップ」 | この画面のデスクトップを1枚残す |
| 右クリック「範囲を指定…」 | 撮った画像の上で四角を囲んで残す |
| ページの画像の右クリック「🖼 画像を撮影に送る」 | その画像の見えている部分だけを1枚残し、そのまま「大きく開く」。画面に出ている細かさで撮る（ページの拡大率・表示の拡大率に合わせる）。画面の外にはみ出していれば見えている部分だけを残し、そう知らせる。画像の場所が分からないとき（読み込みの途中のページ・枠〈iframe〉の中の画像・小さすぎる画像・2 本指で拡大している間など）は撮らずに理由を知らせる。盤面の「画像ファイルを開く…」で開いた画像も同じ。カードは「中央のページ」として残る。録画中は撮らない |
| 盤面のセル・タブのセルの右クリック「🖼 画像を撮影に送る」 | セルに付けた画像（メモのセルの六角形スクショ・入口やボットのセルの画像・タブの見た目の画像）を、画面を撮らずにそのまま残して大きく開く。画像のあるセルだけに出る |
| 下の区画のカードの画像の右クリック「🖼 画像を撮影に送る」 | カードの画像（大きく見た画像の右クリックでも）を、そのまま残して大きく開く |
| カードの「大きく開く」 | 読む画面に画像だけを出す。矢印・四角・蛍光ペン・文字・スタンプを書き込める（スタンプは道具の「スタンプ」で種類を選んでクリック。右クリックでも置ける。置いたスタンプの右クリックで種類の変更・一行の書き直し・消す）。置いた線・四角・文字は、どの道具でも押せば選べ、ドラッグで動かす・つまみで端を変える・Delete で消す・矢印キーで少しずつ動かせる（Shift を押しながら引くと、選ばずに新しく引く）。文字はダブルクリックで書き直し、矢印と四角は Enter かダブルクリックでひとことを書ける。スタンプと四角には番号が付く。キーは 1〜6 で道具、Ctrl+Z で戻す、Ctrl+Y でやり直す、Ctrl+0・Ctrl+=・Ctrl+- と Ctrl+ホイールで拡大（合わせる・100%・200%）、Esc で閉じる。書き込みは画像のファイルには焼かず、AI に送る画像にだけ焼く（スタンプと四角の番号も焼き、文も「印 2」のように番号で指す）。読む画面と送る画像は同じ描き方。「隠す」は四角で囲み、そばの確認で「塗りつぶし」（既定）か「モザイク」を選んで隠す。残す画像に焼き、重なる読んだ文字も「（隠した）」にする。「隠すのを取り消す」で、この画面を閉じるまでは最後の 1 か所を戻せる |
| カードの読んだ行の「隠す」 | その行を画像からも文字からも隠す（塗りつぶし）。「行を選んで隠す…」でまとめて。鍵・メール・電話・カード番号らしき行は「候補」の札が付き、「候補をまとめて隠す」で隠せる（示すだけで、勝手には隠さない） |
| 録画カードの「mp4 だけ消す」 | mp4 の動画だけを消し、代表の画像のカードとして残す（mp4 は隠せないので） |
| カードの「文字を読む」 | 画像の文字を読む（Windows の文字認識。日本語の言語パックが要る。このパソコンの中で読む）。もう一度押すと、前の読みを置き換える |
| カードの「AIに頼む」 | 中身を確かめてから、相棒か Grok Bot に渡す。押しただけでは送らない。相棒へは道具なし（URL を開くなどはしない）で送り、読み取った文字は資料として囲う |
| カードの「ページを開く」 | 中央で撮ったページを開く（URL が残っているとき） |
| 左上のシート名 →「撮ったもの」 | 六角形に縮図と、スタンプの数。ダブルクリックで、右の「撮影」がその件を開く。新しくは撮らない |

- 画像と台帳は `%LOCALAPPDATA%\RocksCellsBrowser\ui-data\` の `captures.json` と `captures\`（録画は `captures\<id>.mp4`）。送るまでは、このパソコンの中だけです
- 「AIに頼む」の確認では、実際に送る画像（書き込みを焼き、隠した所を塗ったもの）と文を見てから送れます。「書き込みを焼く」は外せます
- ❓ と ⚠ の印があるときは、その周り（元の大きさのまま 512px 角）を切り抜いて最大 3 枚添えます（相棒だけ。Grok Bot へは全体の 1 枚）。四角の中も候補になります。確認で外せます。会話の画面に出るのは全体の 1 枚だけです
- カードの縮図と拡大にも書き込みが重なって見えます。カードの右クリック「書き込みつきでコピー」で、書き込みを焼いた画像をコピーできます（コピーした画像は、あとで隠しても変わりません）
- 送った文は、相棒の会話記録（`conversations\`）にも残ります。撮影から送った画像は会話記録に残しません（その会話を続けている間は画面に出ます。この版より前に送った画像は、その会話を消すまで残ります）。送ったあとで隠しても、送った先の写しは隠れません。Grok Bot へはクリップボードを通ります
- 録画は中央のページだけ。録画中は、ほかの撮影と「文字を読む」はできません。録画中に窓を閉じても、そこまでの mp4 は残します
- 録画カードで隠しても、mp4 の動画は隠れません（「mp4 だけ消す」で消せます）。隠したあとの「文字を読む」は、代表の画面だけを読みます
- 撮影の一覧（`captures.json`）を読めなかったときは、上書きしないように撮影の保存を止めます（開き直すと、もう一度読みます）
- 盤面・下の区画から送った画像は、カードの範囲の表示が「盤面のセルの画像」「タブの見た目の画像」「下の区画のカードの画像」になり、大きく開いた画面の題名に元の名前（メモやタブの題名）が付きます。台帳のカードには省いてよい項目 `from`（`kind` と `name`）が付きます（`version` は 1 のまま。古い版で開いても消えず、古い版では「囲んだ範囲」と出ます）。元の画像（`ui-data\shots\`）は動かさず、撮影のカードを消しても残ります。データ置き場の画像は、まだ送れません
- 「中央の見えている所」と、下の区画の「▣ 見えている所を画像に」は、スクロールしたページ・拡大したページでも見えている所を撮ります。「⇣ 全体を画像に」も、拡大したページで下や右が欠けません（2026-10-14 に直しました。それまでは、スクロールしたページで黒や白の画像になることがありました。WebView2 の撮影の範囲は、文書の左上からの「CSS ピクセル × ページの拡大率」で数えるため）
- 実装：ページの画像は `src/tabs.cpp`（`WatchContextMenu` の項目・見張りのスクリプト `kImageHookScript`・`CaptureViewport` の `rect`）と `ui/src/panels/capture-panel.ts`（`shootImage`。撮る直前に、ページに画像の見えている矩形を測ってもらう）。盤面・下の区画の画像は `capture-panel.ts` の `keepShot`（`ui-data\shots\` を読む）、入口は `ui/src/app/primary.ts`（`queueCellImage`・`captureCardImage`）と `ui/src/app/memo-pane.ts`
- 盤面のセルは `memocells.json` の省いてよい項目 `capture`（`version` は 1 のまま）。撮影を消すのは、右の「撮影」だけです

## ビルドと起動

### Visual Studio で
1. Visual Studio を起動し、「ローカル フォルダーを開く」でこのフォルダを開く
2. 上部の「スタートアップ項目の選択」で `RocksCellsBrowser.exe` を選ぶ
3. F5 で実行

### コマンドで
```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```
`-Release` でリリース版、`-NoRun` でビルドのみ。C++ と UI（TypeScript）の両方がビルドされる。

### UI だけを普通のブラウザで試す
```powershell
npm --prefix ui run dev
```
http://localhost:5173 を開くと、C++ 側の代わりに簡易版の偽物で動く。見た目や操作を素早く試すとき用。
右サイドバーの見た目は http://localhost:5173/?surface=right で確認できる。下のメモの区画は、同じブラウザの別のタブで http://localhost:5173/?surface=memo を開く（左の盤面でメモを開くと、そちらへ写しが届く。ページの文と画像は見本）。

### URL を渡して起動する（ほかのソフトからこのブラウザで開く）
```powershell
RocksCellsBrowser.exe http://localhost:8787/
```
- 引数の **http / https の URL** を、新しいタブで開く（それ以外の引数・URL は無視）。引数が無いときは今までどおり。
- 同じデータフォルダで Rocks-cells Browser が **すでに動いていれば、窓は増やさず**、動いている窓へ URL を渡して前に出す（`WM_COPYDATA`）。環境変数 `ROCKSCELLS_DATA_DIR` でデータフォルダを分けた窓（テスト用）には渡さない。
- 同じページ（`#` 以降と、最後の `/` の有る無しは見ない）のタブがすでにあれば、新しく作らずそのタブを出す。前回のタブを並べ終えてから決めるので、前回のセッションに入っているタブも見つかる。
- 実装：`src/main.cpp`（引数の取り出しと、動いている窓への受け渡し・受け取り）、`src/browser.cpp`（`OpenExternalUrl`。UI の準備ができてから `openUrl` を送る）、`ui/src/app/primary.ts`（`openExternalUrl`）。

## 使い方

| 操作 | 小さい表示（ハニカム） | 大きい表示（リスト） |
|---|---|---|
| タブを表示 | セルをクリック | 行をクリック |
| 移動・並び替え | セルをドラッグ（他のセルの上なら入れ替え） | 行をドラッグ（番号が振り直される） |
| 閉じる | 中クリック | × ボタン / 中クリック |
| 新しいタブ | 空きセルをダブルクリック / ＋ / Ctrl+T | ＋ / Ctrl+T |
| 新しいタブを裏で開く（ページはこのまま） | ページのリンクを右クリック →「セルに追加（ページはこのまま）」 / アドレスバーで Alt+Enter | 同じ |
| 盤面を動かす | 2本指スワイプ / ホイール（Shift で横）/ 背景をドラッグ | 2本指スワイプでスクロール |
| 拡大縮小 | ピンチ / Ctrl+ホイール / 右下の ＋ − | — |
| 今のタブへ戻る | 右下の ◎ | — |

- 新しいタブは、開いた元のタブの隣のセルに置かれ、番号は元のタブの直後になる
- Ctrl+W で閉じる、Ctrl+L でアドレスバー、Ctrl+Tab / Ctrl+Shift+Tab で番号順に切り替え（今見ているシートの中で）
- ページの上での2本指の横スワイプは「戻る / 進む」
- `#` で小さい表示にも番号を出す。表示の設定・盤面の位置は次回も覚えている

### 見た目（テーマ）

左の表示のバーの ◐（「見た目」）で小窓が開く。テーマを押すと、左・右・読む画面・下のメモの区画が一緒にすぐ替わる（アニメは無し）。閉じて開いても残る。外を押すか Esc で閉じる。

| 選び方 | 中身 |
|---|---|
| 自動（Windows の明暗に合わせる） | 既定。上の段（明るい 8）から「明るいとき」、下の段（中間と暗い 5）から「暗いとき」のテーマを 1 つずつ選ぶ。既定は 蜜蝋 と 炭 |
| いつも同じテーマ | 13 から 1 つ。切り替えたときは、今見えているテーマのまま固定する |
| ページの明暗もテーマに合わせる | いつも同じテーマのときだけ効く。入れていると、暗い色に対応したサイト（タブ）もテーマの明暗で出る（WebView2 のプロファイル全体の設定）。外すと Windows に従う |
| 既定に戻す | 自動・蜜蝋・炭に戻す |

- テーマ：明るい 蜜蝋（今までの明るい色を直したもの）・白磁・生成り・古紙・若葉・暁・雲母・墨と白（線の濃い明るいテーマ）、中間と暗い 薄暮・炭（今までの暗い色を直したもの）・夜の巣・青図・黒板。どのテーマでも、文字と地は 4.5:1、印と枠は 3:1 を下回らない（`ui/test/themes.test.ts` が全部確かめる）
- 窓の題名バーと枠もテーマの色になる（Windows 11。Windows 10 では暗い枠かどうかだけ）。次の起動では、窓を作る前に前回の色で開く
- そのまま固定の色：月の窓（夜空）・星空の回答カード・相棒とハイク組の顔の飾り・撮ったものを見る暗い画面・画像に書く色
- データの色（タグ・シート・島・順路・関連の線）は、保存した色のまま、描くときだけテーマの明るさの帯に収める（明るいテーマでは濃く、暗いテーマでは明るく。`ui/src/data-colors.css`）。色の上の字は、明るいテーマでは白、暗いテーマでは墨
- 保存：テーマの選び方は localStorage の `honeycomb.theme`（4 つの面で共有）。窓の色は `%LOCALAPPDATA%\RocksCellsBrowser\theme.json`（消すと、今までどおり白い窓で開く）。台帳（`session.json`・`ui-data\`）は変えていない
- Windows のコントラスト テーマを入れているときは、Windows の色が勝つ
- 開発中（`npm --prefix ui run dev`）は、URL に `?theme=<id>` を付けると、そのテーマで開く。`?theme=check` は、決め打ちの色の直し残しを浮かせる派手な検査用テーマ（本物のビルドには入らない）


### セルを選ぶ・範囲コピーと貼り付け・セット
六角メモと同じように、セルをまとめて選んで、**同じ並びのまま** コピー・貼り付けできる。よく使う並びは **セット** として保存して、右クリックから一手で開ける（六角メモの「定型」と同じ考え。朝のルーティンなど）。

| 操作 | 内容 |
|---|---|
| `Ctrl`+クリック | セルを選ぶ（もう一度で外す。リストの表示でも使える） |
| `Shift`+クリック | 前に選んだセルから、押したセルまでの四角の中を選ぶ |
| `Esc` ／ 空いた所をクリック | 選択を解除 |
| 選んだセルを右クリック | コピー／セットとして保存…／島を全部選ぶ／選択を解除 |
| 空いたセルを右クリック | 新しいタブ／貼り付け（何を貼るかが出る）／セットを貼る（貼り方：ここに並べる・入口を1つ置く）／セットの一覧（名前を変える・消す）。下の方に「シートへ移る」（登録したシートのボタン・シートのセット・その他のシート） |
| `Ctrl`+`C` ／ `Ctrl`+`V` | 選んだセルをコピー／マウスの位置（空いたセル）か、今のタブの近くに貼り付け |

- 貼るときは、右クリックしたセルを左上にして同じ並びで、眠ったタブとして置く（開くと読み込む）。ほかのタブと重なるときは、形を保てる近くの空いた場所へずらす
- コピーは Windows のクリップボードに **六角メモと同じ形** で書くので、六角メモに貼るとリンク付きのマスが同じ並びで並ぶ。ほかのアプリには「題名と URL」の文字として貼れる
- 六角メモでコピーしたマスも貼れる（リンクの付いたマス・本文に URL があるマスだけ。URL の無いマスは飛ばす）。ほかのアプリでコピーした URL の一覧（1行に1つ）も貼れる
- 同じ島のセルをまとめてコピー・保存すると、貼るときに同じ名前と色の島ができる。題名・アイコン・タグ・♥ も一緒に写る（メモは写さない）
- セットの保存先は `ui-data\cellsets.json`（100 個まで。1つ 60 セルまで）
- セルを1つ右クリック →「画像を貼る」で、クリップボードの画像（長い辺 1600px まで）をそのセルの顔にする。ページのタブは見え方「画像」、メモ・入口・ボットはセルの画像。アプリと撮ったものは貼れない。「画像を外す」で戻す

### シート（盤面を何枚も）とシートへの入口
ハニカムの盤面を **シート** に分けて、何枚も持てる。いつもある「メイン」のほかに、セットごと・調べものごとのシートを作り、盤面には **シートへの入口**（シートの色でぬった六角形に、白い内枠とシートの名前。右上の数は中のセルの数）を1つ置いておける。

| 操作 | 内容 |
|---|---|
| 空いたセルを右クリック →「セットを貼る」の **貼り方** で「入口を1つ置く」 | そのセルには入口だけを置き、セットは新しいシート（名前はセットと同じ）に、保存したときの並びのまま貼る。どちらの貼り方にしたかは覚えておく（「ここに並べる」は今までどおり） |
| 入口を押す | 盤面がそのシートに変わる（表示中のページはそのまま。そのシートのタブを押すと切り替わる） |
| 左上の ← | 来たシートへ戻る（起動し直した後などは、このシートへの入口があるシートか、メインへ） |
| 左上のシートの名前 ▾ | すべてのシート（押すと移る）・新しいシート（今のシートに入口を置いて移る）・名前を変える・このシートを消す・**このシートをアーカイブ…**・**アーカイブの一覧…**・タブの見え方（すべてのシート） |
| タブやメモのセルを入口に落とす | そのシートへ移す（入口どうしは場所の入れ替え） |
| 選んだセルを右クリック | **入口1つにまとめる（新しいシートへ）**：同じ並びのまま新しいシートへ移し、いちばん左上のセルに入口を置く／**シート「…」へ移す**（最近見たシートから。多いときは「ほかのシートへ移す…」） |
| 入口を右クリック | シートを開く・名前を変える・見た目（画像・コメント）・**中身をここに出す**（入口の場所に並べ直してシートをなくす）・入口を消す（シートは残る）・シートごと消す（中のタブを閉じる。数を見せて確かめる） |
| 盤面を右クリック →「シートへ移る」 | 登録したシートのボタン（6つまで。押すと、そのシートに移る）・**このシートをボタンに登録…**・**シートのセット…**・**その他のシート…**。上にある「メモを書く」「下に開いて書く」などは、今までどおり |

- ボタンの登録は、右サイドバーの見出しのタグと同じです。盤面を右クリック →「このシートをボタンに登録…」→「シート1に登録」から「シート6に登録」（入れるのは、いま見ているシート）。同じシートは1つのボタンだけです。別のシートを同じ番号に入れると、前のものは外れます。まだ何も入れていない番号のボタンは出ません。いまのシートのボタンは、うすい金色です
- 覚えておく場所は、この画面の中だけです（`session.json` も `right-sheets.json` も `cellsets.json` も変わりません）。消したシートのボタンは、次にメニューを開いたときに外れます
- **シートのセット…** は、右のメモで「保存」したセットの一覧です。名前を押すと中のシートが出て、選ぶと盤面がそこに移ります。右のメモのタブは動きません（セットを「開く」ことにはなりません。シートは消えません）
- **その他のシート…** は、6つのボタンに入っていないシートです。押すと、そのシートに移ります
- 書きかけの欄が開いているときは、今までどおりシートには移れません（「残す」か「やめる」で閉じてから）
- 番号（`#` と大きい表示）と Ctrl+Tab はシートの中だけで数える。大きい表示（リスト）も今のシートのタブだけ
- 相棒の道具・順路・リマインダーなどで別のシートのタブを開いたときは、盤面もそのシートへ移る（タブを閉じた後に自動で選んだタブは除く）。右下の ◎ は、表示中のタブのシートへ移って中心に
- ＋・ダブルクリックの新しいタブは、今見ているシートに置く。ページのリンクから開いたタブは、元のタブのシートに置く
- 盤面の位置と拡大率はシートごとに覚える。シートの台帳と見ていたシートは `session.json` に保存する（次に起動すると、見ていたシートから）
- 入口とシートは相棒にも見える（タブの一覧に、メイン以外のシートの名前とコメントが付く）。入口はコピー・セット・六角メモへ送るものには入らない

### シートのアーカイブ（保存して片付け、一覧から戻す）
シートを、中のタブ・メモのセル・入口・画像の参照・島・盤面の位置ごと **アーカイブ** に保存して、盤面から片付けられる。あとで **アーカイブの一覧** から、同じシートとして戻せる。

| 操作 | 内容 |
|---|---|
| 左上のシートの名前 ▾ →「このシートをアーカイブ…」 | 数（タブ・メモのセル・ほかのシートからの入口）を見せて確かめ、「アーカイブする」で保存してから片付ける。メイン・撮ったもの・右のメモのシートでは押せない |
| 入口を右クリック →「シートをアーカイブ…」 | 入口の行き先のシートを、同じようにアーカイブする |
| 「シートを消す」の確かめ | 「消す」「やめる」の間に「消さずにアーカイブする」 |
| 左上のシートの名前 ▾ →「アーカイブの一覧…」 | 新しい順に 20 件ずつ（「もっと見る」）。行は名前と「タブ n・メモ n・日付」（戻したことがあれば「戻した」）。**戻す**（同じシートが盤面にあれば **足りない分を戻す**）・**消す**（「本当に消す」） |

- 保存してから、書いた中身を読み返して確かめ、そのあとで片付けます。どこかで失敗したら、シートはそのままです（「シートはそのままです」と出ます）
- 戻すのは **足すだけ** です。今あるタブ・メモ・シート・島は消しも上書きもしません。シート・メモ・島の id、位置、名前と色は元のまま。タブは眠ったタブとして戻り、番号だけ新しくなります
- 同じシートが盤面にあるときは「足りない分を戻す」：無いメモ・入口と、そのシートに同じページが無いタブだけを足します。全部あれば「もう全部戻っています」
- ほかのシートにあった、このシートへの入口も、アーカイブして消し、戻すときに元の場所（埋まっていれば近く）へ置き直します。中の入口の行き先（子のシート）は、まとめずに盤面に残ります
- 戻せないもの：行き先のシートがもう無い入口、台帳に無いボット・アプリのセル、元のシートが無い入口（数を知らせます）。右のメモのシートのタブ・セットからは、アーカイブで外れ、戻しても戻りません。シートのボタンの登録も外れます
- アーカイブは自動では消えません（戻した後も残ります）。消すのは一覧の「消す」→「本当に消す」だけ
- アーカイブで閉じたタブは、左の下の棚の「最近閉じた」には入りません
- 保存先：`ui-data\sheet-archive\<id>.json`（本体）と `ui-data\sheet-archive-meta\<id>.json`（一覧の札）。画像は写さず、`shots\<id>.json` を id で参照します

### タブの見た目（画像・コメント・見え方）
タブのアイコンに **画像** と **コメント** を付けて、盤面での見え方を選べる。

| 操作 | 内容 |
|---|---|
| タブを右クリック →「見た目（画像・コメント）…」 ／ 拡大表示のカードの「見た目」 | セルの近くに見た目の欄が開く |
| 画像を選ぶ… | パソコンの画像を選ぶ（長い辺 256px に小さくして `ui-data\shots\` に保存。インターネットへは送らない） |
| ページの画面から | このタブのページの縮図を画像にする（一度表示したページだけ） |
| 六角形に切り取る… | 表示中のページを六角形スクショと同じ操作で切り取り、そのままタブの画像にする（書いたひとことはタブのコメントに） |
| Ctrl+V | 欄が開いている間は、コピーした画像・スクリーンショットを貼れる |
| コメント | 1行・40文字まで。画像の上では小さな印（“）だけを出し、マウスを乗せると吹き出しで全部見える |
| このタブの見え方 | 全体に合わせる・おまかせ・アイコン・画像・コメント・ページの画面 |

- 全体の見え方は、左上のシートの名前 ▾ の「タブの見え方」：**おまかせ**（付けた画像とコメントを見せる。無ければアイコン）・**アイコン**（今までどおり）・**画像**・**コメント**（コメントの無いタブは題名を薄く）・**ページの画面**（表示したことのあるタブだけ。無ければアイコン）
- 大きい表示（リスト）では、画像を見せる見え方なら六角形のアイコンが画像に、コメントは題名の下に出る。拡大表示のカードにも画像とコメントが出る（右サイドバーのカードも）
- 画像・コメント・見え方は `session.json` に保存し、コピー・セットにも一緒に入る（六角メモへ送るときは、今までどおり文字だけ）
- シートへの入口にも、同じ欄で画像とコメントを付けられる

### メモのセル
盤面に、ページではない **メモのセル**（紙の色の六角形）も置ける。WebView を持たないので軽く、眠らせることもない（第1段）。

| 操作 | 内容 |
|---|---|
| 空いたセルを右クリック →「メモを書く」 | そのセルにメモを書く（`Ctrl`+`Enter` で残す・`Esc` でやめる。空のままなら作らない） |
| ほかのアプリでコピーした文章を貼る | URL の無い文章はメモのセルになる。URL を含む文章は、タブにするほか「文章のままメモのセルにする」も選べる |
| 六角メモでコピーしたマスを貼る | リンクの無いマスはメモのセル（本文・タグ・♥）、リンクのあるマスはタブになる（同じ並びで） |
| メモのセルを押す ／ マウスを乗せる | 拡大表示にメモのカード（全文・タグ・♥・作った日時） |
| ダブルクリック | 下のメモの区画で開く（中央を上下に分ける。開き方・閉じ方は下の「メモの分割」） |
| 右クリックの「書き直す」 ／ カードの「書き直す」 | 盤面の上の小さな欄で書き直す |
| ドラッグ | 動かす（タブやほかのメモの上に落とすと、場所を入れ替える） |

- カードのボタン：下で開く ⬓（開いていれば「下の区画を閉じる」）・♡（いいね）・書き直す・リンクを開く（本文に URL があるとき）・相棒に見せる（右の相棒がメモについてコメント）・六角メモへ（送り先のノートへ）・消す（2回押す）
- 選ぶ・コピー・貼り付け・セット・島は、タブのセルと同じ（タブとメモを混ぜて選べる）。コピーすると六角メモにはメモのマスとして貼れる
- 大きい表示（リスト）には出ない（盤面だけ）
- カードの下で **コメントを追加** すると、メモの文章を元のポストにして、X の返信のようにコメントをつなげられる（下の「コメントのスレッド」）。メモのセルのコメントは、下のメモの区画でも同じものを書く

### メモの分割（中央を上下に分けて書く）
盤面の **メモのセル** を開くと、真ん中のページの場所が上下に分かれる。上は今までどおりのページ、下はそのメモを書く区画。入口とボットのセルは、ダブルクリックしてもこの区画は開かない。

**開き方**

| 操作 | 内容 |
|---|---|
| メモのセルをダブルクリック | 下の区画でそのメモを開く。盤面のそのセルに金色の太い枠が付く |
| 右クリック →「下に開いて書く（中央を上下に分ける）」 | 同じ。開いているメモなら「下の区画を閉じる」 |
| 拡大表示のカードの「下で開く ⬓」 | 同じ。開いていれば「下の区画を閉じる」 |
| `Ctrl`+`Shift`+`M` | 開く・閉じる。閉じたあとにもう一度押すと、最後に開いていたメモが開く |

別のタブに切り替えても、下は同じメモのまま。上のページだけ替わる。帯の右の「上：」が、今のページの題名。起動し直したときは、下の区画は閉じたまま（高さと、最後に開いたメモは覚えている）。

**閉じ方**

- 見出しの行の右の「閉じる（Esc）」
- 下の区画で `Esc`。本文・コメント・書き直しの欄の中にいるときは、1回目の `Esc` はその欄から出るだけ。欄の外でもう一度押すと閉じる
- 盤面の右クリック「下の区画を閉じる」、拡大表示のカード、`Ctrl`+`Shift`+`M`
- 開いているメモのセルを消すと、下の区画が閉じて「メモが消されたので、下の区画を閉じました」と出る

閉じると、ページは元の高さに戻り、キーボードの入力先もページに戻る。

**高さ**

下の区画のいちばん上の細い帯（マウスを乗せると金色）を上下にドラッグする。上へ大きく引いても、下へ引いても、途中で外れない。ページはこれ以上縮まない高さ（200）を残す。下の区画は 120〜1,600。初めて開くときは 300。帯を選んで ↑↓ キーでも 20 ずつ変わる。閉じても、次に開いたときは同じ高さ。

**帯（見出しの行のすぐ下）**

見出しは本文の最初の行（空なら「（空のメモ）」）。帯のボタンは、上のページを使ってカードを足す。

| ボタン | 内容 |
|---|---|
| ❝ 選んだ文を引用 | 上のページで選んだ文を、引用のカードにする。選んでいないと、帯の下に「上のページで文を選んでから押してください」 |
| ▣ 見えている所を画像に | 上に見えている所の画像のカード。下の区画は写らない |
| ⇣ 全体を画像に | スクロールで隠れた所も含めて1枚の画像にする。ページによっては、きれいに撮れないこと・撮っている間に一瞬ちらつくことがある |
| 🖼 画像を選ぶ | パソコンの画像をカードにする。下の区画へ画像を落とす、`Ctrl`+`V` で貼る、でも同じ |
| ⧉ まとめてコピー | 本文とカードを Markdown にしてコピーする。メモ帳に貼れる。画像は「［画像］」とだけ書き、画像の中身は入れない。関連のあるカードの下には「関連：「題」の根拠」の行が入る。カードは並べた順（タグで絞っていても、つながり順でも、全部のカードを並べた順で写す。返信は作った順） |
| ＋ 新しいメモ | 今見ているタブの近くに、空のメモのセルを置いて下で開く。金色の枠が付く。タブが無い・別のシートのときは、今見ているシートの真ん中の近く |
| このタブに移動 | 左の盤面で、今開いているメモのセルへ移る。別のシートなら切り替え、見える所まで動かして少し光る。セルが消えていれば、帯の下に「そのメモのセルは、もうありません」 |
| ☰ | メニュー。「一覧を出す」と「上のページのリンクを入れる」 |

**メモの一覧（帯の題名から）**

帯の「メモ：題名 ▾」を押すと、帯のすぐ下にメモの一覧の小さな窓が浮く（☰ →「一覧を出す」でも同じ）。区画の高さも、本文やカードの並びの幅も変わらない。区画が低いとき（帯の下に 120 ほど入らないとき）は、帯の上にも重なる。

- 窓の中は、上から「見出しで絞る」の欄、札「このシート n｜最近 n」、メモの名前の一覧。札で、今のシートのメモ（新しい順）か、最近開いたメモかを切り替える。名前の横に ♥ の段階・🖼（画像のメモ）・相棒の名前が出る。今開いているメモには印
- 名前を押すと、下の中身がそのメモに替わり、窓は閉じる。↓ で絞る欄から一覧へ、↑↓ で名前を選んで Enter でも替わる
- コメントの欄・カードの書き直し・返信の欄に書きかけがあるときは、1 回押すと名前が「書きかけが消えます・もう一度押すと替えます」（赤）になり、もう一度押すと替わる
- `Esc`・窓の外を押す・題名をもう一度押すと閉じる（区画は閉じない）。札の選びと絞った字は覚えない（閉じると「このシート」と空に戻る）

「見出しで絞る」をクリックして入力できる状態にすると、そのすぐ下に次が出ます。欄から離れるか、Esc で閉じます（Esc をもう一度押すと、欄の字が消えます）。字を入れて絞る動きは、今までどおりです。

- **登録したワード**（6つまで。丸いボタン）。押すと、そのワードで絞ります。長い名前は「…」で切れ、マウスを乗せると全部出ます。空の番号は出ません。いま絞っているワードのボタンは、薄い金色です。
- **このワードをボタンに登録…**：いま欄に入っているワードを、ワード1〜6に入れます。同じワードは1つだけです。別の番号へ入れると前の番号から外れ、入っていたワードは外れます。ワードは40字までです。
- **ワードのセット…**：6つのボタンを1組として保存し、切り替えます（12組まで）。切り替えても、いま絞っている字は変わりません。新しいセット・いまの6つの複製・名前の変更・削除（最後の1組は消せません）も、ここからできます。
- **その他のワード…**：6つのボタンに入っていない、最近絞ったワードです（12件まで）。押すと、そのワードで絞ります。

覚えている場所は、下の区画だけの localStorage（`honeycomb.memoFilterWords`）です。メモの台帳や、区画の高さと最近開いたメモを覚えている `honeycomb.memoPane` は変えません。

ページで文を選んで右クリック →「📝 下のメモに引用」は、下の区画が開いているときだけ出る。`Ctrl`+`Shift`+`Q` でも、選んだ文を引用できる。

**本文とカード**

本文は、打つのをやめて少し待つと保存される。帯のすぐ下の細い1行に「保存しました」と時刻が出る。止まったときも、この1行に段の名前が出る（例：「コピー：書けない」「リンク：ページなし」）。

本文の下に、コメントのカードが作った順（並べ替えると並べた順。下の「カードを並べ替える」）に並ぶ。いちばん下の「＋コメント」に書いて `Ctrl`+`Enter` か「足す」で足す。足したカードは最後に入る。

- **280字は目安。** 書く欄の「123 / 280」が、280を超えると橙になる。カードでは 280字まで見せて「…続き ▾」。上限は 2,000字（それより先は入らない）。1つのメモの返信は 300件まで
- カードの「書き直す」で文を変えると、頭に「書き直し済み」。相棒が書いた返信は書き直せない
- カードの「💬」で、そのカードへの返信。何段でもつながる
- 種類の印：💬 コメント、❝ 引用、🖼 画像、🔗 リンク（文の無いページのリンク）

**カードのタグと、タグで絞る**

- カードの頭の「＋タグ」で、そのカードにタグを付ける。書く欄の下に候補の欄が出る：上に「登録したタグ」（右サイドバーのタグのボタンの今のセットの 6 つ。セットの名前つき）、横線、下に「その他」（このメモのカードのタグ・メモのタグ・六角メモのタグ）。字を書くと両方が絞られ、↑↓ で選んで Enter、または押して付ける（何も選ばずに Enter なら、書いた字で付ける）。もう付いているタグは「✓」で押せない。右サイドバーでボタンを登録していなければ、登録したタグの区画は出ない。付いたタグの × で外す。1 枚に 10 個まで。タグを付けられるのは一番上のカードだけで、返信はそのカードと一緒に出る・隠れる。タグが「グループ」の代わりで、1 枚に複数のタグ（＝複数のグループ）を付けられる
- カードにタグがあると、本文の下に「すべて n」とタグの札が並ぶ（枚数の多い順に 12 個まで。あふれたタグは「その他 ▾」）。押すと、そのタグのカードだけを出す。もう一度押すか「すべて」で戻る。選べるのは 1 つ。札はスクロールしても上に残る。どれを選んだかは覚えない（メモを替えると外れる）
- 絞っている間は、件数の行が「コメント 表示 m ／ 全 n」になる
- 絞っている間に足したカード（「＋コメント」・引用・画像など）には、選んでいるタグが自動で付く（絞りは外れない）
- 右の「検索」から、絞りで隠れているカードへ移るときは、絞りを外して「タグの絞りを外しました」と出る
- カードのタグはメモの台帳に入る。メモの「更新」の時刻は変えない

**カードの関連（種類つきの線）**

一番上のカードどうしを、種類つきの「関連」で結べる（返信の木 💬 とは別）。関連は「元 → 相手」の向きで持ち、**元のカードは相手の〈種類〉** と読む。

| 種類 | 線の色と形 | 読み方 |
|---|---|---|
| 根拠 | 緑・三角の矢じり | 元は相手の根拠 |
| 反論 | 赤・止めの棒 | 元は相手への反論 |
| 続き | 青・山形の矢じり | 元は相手の続き |
| 同じ | 灰・矢じりなし | 元と相手は同じ（向きなし） |
| 疑問 | 紫・破線・丸の矢じり | 元は相手への疑問 |

- **結ぶ**：元のカードの「🔗 関連づける」を押すと、状態の行に「…の相手のカードを押してください」の帯が出る。相手のカードのどこかを押すと、種類の小さな欄が出るので選ぶ。帯の「一覧から選ぶ」で、字で絞れる相手の一覧から選んでもよい（キーボードで「🔗 関連づける」を押したときは、この一覧が開く）。`Esc` で小さな欄 → 関連づけるのをやめる、の順に閉じる（区画は閉じない）
- 同じ二枚のあいだの関連は、向きごとに 1 本（種類を選び直すと置き換え）。逆向きの「同じ」は持たない。1 枚から 10 本まで。結べるのは一番上のカードだけ
- **見る・外す**：関連のあるカードの頭に「関連 n」（絞りで相手が隠れていれば「関連 n（隠れ m）」）。押すと「このカードは「…」の根拠」「「…」はこのカードの根拠」のような一覧が出て、「移る」で相手のカードへ（絞りで隠れていれば絞りを外す）、「外す」で外す
- **線**：関連のあるカードの間に、カードの隙間を通る線を引く。同じ隙間を並んで通る線は、ずらして重ならないようにする（交わる点はある）。関連があると、カードの間の隙間が少し広がる（列の数が一つ減ることがある）。線に乗せると種類と文が出て、押すと「元へ移る・相手へ移る・この関連を外す」
- **関連の見せ方**：件数の行の右の「関連の見せ方 ▾」で、線を「すべて｜選んだカード（押したカードの線だけ）｜出さない」から選べる。凡例もここ。線が多すぎて隙間に収まらないときは、自動で「選んだカード」になり「線が多いので、選んだカードの線だけ出しています」と出る（「すべて」に戻すと、重なっても全部描く）。見せ方は覚えない（メモを替えると「すべて」）
- 関連は下の区画だけで見せる（拡大表示・右の「メモ」の区画・右の検索には出さない）。相棒に渡す文にも入れない。カードを消すと、ほかのカードからそのカードへの関連も外れる（× の 2 回目の文に「ほかのカードからの関連 n 本も外れます」）
- コピー：盤面でメモのセルをコピーして貼る・セットに入れる・スレッドを丸ごとコピーすると、関連も一緒に写る。カード 1 枚をコピーしたときは写らない（知らせに「このカードの関連は写りません」）

**つながり順とマップ**

- 「関連の見せ方 ▾」の「並べ方：作った順｜つながり順」（並べ替えたメモでは「並べた順｜つながり順」）。つながり順は、関連でつながったカード（向きは見ない）を隣り合わせに並べ、つながりごとに「つながり：「…」ほか n 枚」の見出しを出す。関連の無いカードは最後に「つながりなし（n 枚）」。覚えない
- 件数の行の「並び｜マップ」で「マップ」を押すと、区画いっぱいに関連のマップが重なる（区画の高さは変えない。マップの間は書けない）。関連のあるカードが札になって、つながりがまとまるように動いて止まる（Windows の「アニメーション効果」を切っているときは、動かずに一度に置く）。関連の無いカードは出さない（上の行に枚数）
- 札をつまんで動かすと、そこに止まる（点線の枠）。止めた札をダブルクリックすると止めが外れる。「置き直す」で最初から。札を押す（キーボードなら Enter）と、マップを閉じて並びでそのカードへ移って光る。`Esc`・「× 並びに戻る」で並びへ。マップの形は、そのメモを開いている間は覚えている（メモを替えると忘れる）

**カードを並べ替える**

一番上のカードを好きな順に並べ替えられる（返信はそのカードと一緒に動く）。並びはメモの台帳に入り、開き直しても残る。

| 操作 | 内容 |
|---|---|
| カードの頭の右端の「⠿」（つまみ）を押したまま動かす | カードが薄くなり、ポインターに題の札、置く所の隙間に金色の印が出る。離すとそこへ 1 枚だけ差し込む（間のカードは一つずつずれる）。元の位置で離すと何も起きない。ドラッグの間は、上の札の列と下の「＋コメント」の欄が貼りつかなくなり、区画の上下の端に止めると自動で送る（ホイールでも送れる）。`Esc` でやめる（区画は閉じない） |
| つまみを押す（動かさずに離す）・右クリック・`Enter` | 小さな欄：「← 前へ」「後ろへ →」「いちばん前へ」「いちばん後へ」。並べ替えてあれば「並び　作った順に戻す」（もう一度押すと戻す） |
| つまみに焦点があるときの `Alt`+`←`／`Alt`+`→` | 一つ前・後ろへ。端では「いちばん前です」「いちばん後ろです」と出る |

- 動かすと、状態の行に「「題」を n 枚目から m 枚目へ動かしました（k 枚中）」と出て、カードが少し光り、焦点はそのカードのつまみに残る（読み上げにも同じ文を出す）
- タグで絞っている間は、見えているカードの間で並べ替える。落とした先の見えているカードのすぐ前に入り、隠れているカードどうしの順は変わらない
- 「関連の見せ方 ▾」の並べ方は、並べ替えたメモでは「並べた順｜つながり順」になり、その下に「並び　作った順に戻す」が出る。つながり順の間はつまみが薄くなり、押すと「つながり順の間は並べ替えられません。」と「並べた順にする」。関連づけている間・マップの間は、つまみは何もしない（関連づけている間にほかのカードのつまみを押すと、今までどおりそのカードが相手になる）
- つながり順の中・線の通り道・マップの初めの置き方は、作った順のまま。線が多くて自動で「選んだカード」になっていたときは、並べ替えて隙間に収まるようになれば「すべて」に戻る
- 並べた順は下の区画だけで使う。拡大表示・右の「メモ」の区画・右の検索・相棒に渡す文は作った順のまま（下の区画で開いていないメモを拡大表示で見ると、作った順に見える）
- 盤面でメモのセルをコピーして貼る・セットに入れる・スレッドを丸ごとコピーすると、並びも一緒に写る

**引用・画像・書き出す場所**

- 引用のカードの「↗ 題名」を押すと、そのページの、引用した文の所へ移って色が付く（ページによっては色が付かないことがある。ページは出る）
- カードの画像を押すと大きく見える。`Esc` か × で戻る
- 見えている所の画像・選んだ画像は、データフォルダの `ui-data\shots\` に入る（メモの台帳には、画像の名前だけ）
- ページ全体の画像と、カードの「書き出す」は、ピクチャの **`Rocks-cells Browser`** フォルダ（`ピクチャ\Rocks-cells Browser\`）に JPEG か PNG で残る。カードの「全体の画像を開く」でその画像を開き、「フォルダで見る」でフォルダを開いてそのファイルを選ぶ。とても長いページは途中で切れ、カードに「途中までです」と出る。古いファイルは消さない

**左下の拡大表示**

盤面の下（「下に固定」）と、盤面の上に浮かしているカードに「📌 固定」がある。押しているあいだは、ほかのセルにマウスを乗せてもカードが替わらない。もう一度押すと外れる。起動し直すと外れている。セルのすぐ近くに出る小さいポップアップと、右のサイドバーには出さない。

タブのカードには、そのページを引用しているメモがあると「このページから引用したメモ n件」と出る。押すと、そのメモが下の区画で開く。2件以上のときは名前の一覧が出る。

下で開いているメモを拡大表示で見ると、「下で開いています」と出て、コメントの並びは「コメント n件（下の区画で見る）」の1行になる。下を閉じると、拡大表示でもふつうのコメントの並びになる。

**データの置き場所と、古い版に戻すとき**

- メモの本文・コメント・引用は `%LOCALAPPDATA%\RocksCellsBrowser\ui-data\memocells.json`（`version` は 1 のまま。足したのは、返信の中の省いてよい項目だけ）
- カードの画像は同じ `ui-data\shots\`
- 初めてコメントを書き直したとき、または引用・画像つきのコメントを初めて足したときに、その直前の台帳を `ui-data\memocells-before-memo-split.json` に **1回だけ** 写す（もうファイルがあれば上書きしない。ただし、そのファイルが壊れていて読めないときは、書き直すことがある。下の写しも同じ）（2026-10-14 に名前を直した。前の名前は C++ の名前の検査に通らず、写しは作られていなかった）
- 下の区画のカードに初めてタグを付けるときに、その直前の台帳を `ui-data\memocells-before-card-tags.json` に **1回だけ** 写す（もうファイルがあれば上書きしない。台帳を読めた起動のときだけ）
- 下の区画のカードに初めて関連を付けるときに、その直前の台帳を `ui-data\memocells-before-card-links.json` に **1回だけ** 写す（タグと同じ決まり）。関連は返信の中の省いてよい項目 `links`（`version` は 1 のまま）
- 下の区画のカードを初めて並べ替えるとき（「作った順に戻す」も含む）に、その直前の台帳を `ui-data\memocells-before-card-order.json` に **1回だけ** 写す（タグと同じ決まり）。並びは返信（一番上のカードだけ）の省いてよい項目 `rank`（0 からの番号。動かすたびに全部振り直す。`version` は 1 のまま）。メモの「更新」の時刻は変えない
- 「登録したタグ」は、右サイドバーのタグのボタンのファイル `ui-data\tag-buttons-right.json` を、下の区画が読むだけ（書くのは右サイドバーだけ）
- 高さ・最後に開いたメモ・最近開いたメモは、このパソコンの中だけに覚える（`memocells.json` には入らない）。一覧の窓・関連の見せ方・並べ方の切り替え（並べた順｜つながり順）・マップの形は覚えない（並べた順そのものは台帳に残る）
- ページ全体の画像は、上のピクチャのフォルダ。アプリのデータを消しても、ピクチャのファイルは残る

古い版のアプリに戻すと、文が空の引用・画像だけのコメントと、書き直した時刻・引用・画像・書き出したファイルの名前は消えることがある（古いアプリが、知らない項目を捨てる）。カードのタグも、古い版では消える（タグを付ける前の写しは `memocells-before-card-tags.json`）。カードの関連も同じく古い版では消える（関連を付ける前の写しは `memocells-before-card-links.json`。写しは関連を付ける前のものなので、消えた関連は写しからは戻らない）。カードの並びも古い版では消え、作った順に戻る（並べ替える前の写しは `memocells-before-card-order.json`。写しは並べ替える前のものなので、消えた並びは写しからは戻らない）。戻す前に `memocells-before-memo-split.json` を見て、必要なら `memocells.json` をその写しに戻す。ピクチャに書き出した画像は、版を戻してもフォルダに残る。

### アプリのセル（Windows のアプリを盤面に登録する）
盤面に、タブ・メモのセルと並ぶ **アプリのセル**（青緑の六角形に、アプリのアイコン。アイコンが取れなければ名前の頭の1文字）を置ける。ダブルクリックすると、そのアプリの窓を **中央の区画**（左の盤面と右のサイドバーと、下のメモのあいだ）の位置と大きさに合わせ、ほかの窓より前に出し続けます。ブラウザを動かしたり大きさを変えたり、サイドバーや下のメモを開閉したりすると、その窓も付いてきます。

| 操作 | 内容 |
|---|---|
| 空いたセルを右クリック →「アプリを登録…」 | `.exe` か、スタートメニューのショートカット（`.lnk`）を選ぶ。同じファイルが既にあれば、台帳は増やさず、そのセルに置く |
| 空いたセルの丸いボタン | 登録してあるアプリ（新しい順に6つ）。押すと、同じアプリのセルをもう1つ置く。7つ目からは「その他のアプリ…」 |
| ダブルクリック ／「中央に出す」 | 既にある窓を中央に合わせ、最前面にする。無ければ起動して、窓が出るのを待つ（約8秒）。もう一度ダブルクリックすると最前面をやめる（窓は閉じない。位置もそのまま） |
| ブラウザをドラッグ・大きさを変える | 最前面の窓が、中央の区画に付いてくる。ドラッグの途中でフォーカスは奪われない |
| サイドバーの幅・下のメモの開閉 | 中央の区画が変わると、窓も一緒に縮む・広がる |
| ブラウザを最小化 | 外の窓は隠れる（タスクバーには増えない）。戻すと、また中央に出る |
| 右クリック「最前面をやめる」 | 追従をやめる。別のアプリをダブルクリックしたとき、セルを外したとき、ブラウザを終了するときもやめる。開いているアプリの窓は残す |
| 右クリック | 名前を変える・ファイルを選び直す・セルを外す（台帳には残る）・台帳からも消す |

- 大きさを変えられない窓（電卓など）は、区画いっぱいにせず、中央に寄せます。区画より大きいときは、一度だけ「サイドバーに重なることがあります」と出ます
- 使う人が外の窓を自分でドラッグしても、次にブラウザが動くと中央に戻ります。自由に置きたいときは「最前面をやめる」
- 窓を閉じると追従は終わり、セルは残ります。もう一度ダブルクリックすると、また開いて中央に出ます
- **ストアアプリ**（設定、Windows 11 の電卓など。窓は `ApplicationFrameHost.exe`）は、ショートカットのアプリ ID で、登録したアプリの窓だけを掴みます。`System32\calc.exe` ではなく、スタートメニューのショートカットを登録します。ID が無く、題名でも特定できなければ、「窓を特定できませんでした」と出て、ほかのアプリの窓は動きません
- 管理者として動いているアプリは、普通の権限のブラウザからは窓を動かせません。「窓を動かせません」と出て、最前面にはしません。ブラウザ自体を管理者で開く必要はありません
- アプリのセルは、コピー・セット・六角メモへ送るもの・下のメモの区画には入りません。右の蜂の巣では「アプリ」と出ます。クリックでは窓を開かず、拡大表示に名前とファイル名が出ます
- 台帳は `%LOCALAPPDATA%\RocksCellsBrowser\ui-data\apps.json`（100件まで。書くのは左サイドバーだけ）。セルの位置は `memocells.json` の `app` です。セルを外しても台帳は残ります

### ボットのセル（Grok Bot への窓口。任意のボット連携）
盤面に、タブ・メモのセルに並ぶ3つ目の仲間として **ボットのセル**（石板の色の六角形に四角い頭。左上に外へ出る矢印）を置ける。中身は外にいる **Grok Bot** への窓口で、押すと **Grok Bot アプリのそのボットのチャット** が開く（第1段）。相棒（Claude など、ブラウザの中の AI）とは別物で、時間のかかる調べもの・決まった時刻の仕事などを受け持つ。

| 操作 | 内容 |
|---|---|
| 空いたセルを右クリック →「ボットのセルを置く…」 | 新しいボット（Grok Bot アプリの「リンクをコピー」で取ったリンクか id を貼り、名前を決める）か、台帳のボット（置いていないものが先）を置く。1体のボットを何個のセルに置いてもよい |
| ボットのセルを押す | Grok Bot アプリのそのボットのチャットを開く（はじめての1回だけ「外のアプリを開きます」と確かめる）。拡大表示にボットのカード |
| 右クリック | アプリで開く・リンクを貼る（貼り直す）・名前を変える・コピーしてアプリを開く・クリップボードの返事をメモにする・見た目（画像・コメント）・セルを外す（台帳には残る） |
| カード | 名前・エージェントの id・状態（ふつう／リンクなし／アプリなし）と、同じことができるボタン。外したあとのカードの「置き直す」で、同じ所（ふさがっていれば近く）に戻せる |
| **コピーしてアプリを開く** | 頼む文を書く欄がセルの近くに開く。「コピーしてアプリを開く」（Ctrl+Enter）で、依頼（`#0003` などの番号つき）を作り、頼む文＋返事の決まり＋依頼の JSON をクリップボードに入れてからアプリのチャットを開く。貼って送るのは自分で（頼む文そのものは保存しない。下の「ボットの返事を受け取る（第2段）」） |
| **クリップボードの返事をメモにする** | アプリでコピーした返事の **最初の 200 字** と字数を見せて確かめてから、ボットのセルの隣にメモのセルとして置く（前にコピーした別の文が、まちがってメモにならないように） |

- 状態：**リンクなし**（左下に「?」。リンクを貼ると開ける）・**アプリなし**（左下に「×」。Grok Bot アプリが見つからなかった。入れてから、もう一度押す）
- 返事のメモは外から来た文として、1行目に「〔Grok Bot「名前」の返事・クリップボードから〕」が付く。相棒の考察の印は付けない（相棒の返事と同じ見た目にしない）。制御文字と、文字の向きを変える文字は消す。リンクは押したときだけ開く（自動では開かない）
- ボットのセルは、コピー・セット・六角メモへ送るもの・コメントのコピーには入らない。タグも付けない。右のメモの区画では「ボット」と出る（アプリを開くのは左の盤面と右下の Grok Bot から）
- **grokbot:// の守り**：ページのリンク・新しい窓（`target="_blank"`・`window.open`）・iframe・リダイレクト・アドレス欄からは grokbot:// を開かない（Grok Bot アプリを開くのは、ボットのセルと右下の Grok Bot だけ）。人が押したリンクを止めたときは、お知らせを出す。アドレス欄にボットのリンクを入れたときは「このリンクで、ボットのセルを置く…」を出す。ほかのスキーム（mailto: など）は今までどおり
- 返事をブラウザで受け取る（中継・受け取り口・右のボットの欄・セルの顔）は、下の「ボットの返事を受け取る（第2段）」。依頼をブラウザから直接送る（Webhook）は、まだ保留

#### しくみ
- セルはメモのセルの一種（`ui-data\memocells.json` の `bot` に、ボットの id だけ）。名前とエージェントの id は台帳 `ui-data\bots\index.json`（`ui/src/bots.ts` の `BotStore`。書くのは左サイドバーだけ）。貼ったリンクから覚えるのは id だけで、リンクそのものは残さない
- 押すと、UI は C++ に **エージェントの id だけ** を渡す（`openBotApp`）。C++（`src/browser.cpp`）が id の形（英数字・_・- の 1〜128 字）を確かめ、`grokbot://` がこの PC に登録されているかをレジストリで見てから、`grokbot://app/v1/agent?id=…` を組み立てて Windows に開いてもらう（URL の形は公開されていないので、変わったら C++ の1か所を直す）
- grokbot:// の守りは `src/tabs.cpp`（タブの `NavigationStarting`・`NewWindowRequested`・`LaunchingExternalUriScheme`）と、アドレス欄（`ui/src/app/primary.ts` の `toUrl`）
- Webhook の URL・キー・ホスト名は、台帳にも UI にも置かない（第2段で C++ の `secrets\` に置く）

### ボットの返事を受け取る（第2段。任意のボット連携）
Grok Bot に頼んだことの返事を、ブラウザで受け取って **右のボットの欄** と **ボットのセルの顔** に出す。依頼はこれまでどおり「コピーしてアプリを開く」で作り、アプリに貼って送るのは自分で。ボットは返事を **中継** に返し、パソコンの道具がそれを取ってきてブラウザに渡す。

```
Grok Bot（アプリのルーティン）
  │ 返事を中継へ送る
  ▼
中継（自分で用意する HTTP の置き場。Cloudflare Workers などで動かす。このリポジトリには入っていない）
  │ 取り出す道具が取ってくる（中継側の道具。これも自分で用意する）
  ▼
置き場 %LOCALAPPDATA%\RocksCellsRelay\inbox\
  │ ブラウザが4秒おきに取り出す（名前を r-＋32 字に変えて移すだけ。中身は変えない）
  ▼
受け取り口 %LOCALAPPDATA%\RocksCellsBrowser\bot-inbox\
  │ <名前>.json → <名前>.taking（取った）→ done\（受け取った）か rejected\（受け取れない）
  ▼
左の UI が確かめて記録する（ui-data\bots\<id>\）→ 右のボットの欄・セルの顔
```

- 置き場に返事を置くのは中継の取り出す道具（自分で用意する。試しは手で動かし、使い始めたらタスクスケジューラーで常駐させる）。ブラウザは置き場から「取り出す」だけで、置き場に書き足したり、ほかのファイルを消したりはしない
- 置き場を見るのは、台帳にボットがいるときだけ（1体もいなければ見回りを止める）
- 返事を受け取るのは、同じデータフォルダで1つの窓だけ。ほかの窓のボットの欄には「別の窓で使っています」と出る（依頼も、受け取っている窓で作る）

#### 依頼（「コピーしてアプリを開く」）
- ボットのセルの右クリック・カード、右下の Grok Bot の「コピーしてアプリを開く」で頼む文を書いて押すと、依頼（`request.v1`）が1つでき、**番号**（`#0003` など）が付く。クリップボードには **頼む文＋返事の決まり＋依頼の JSON** が入るので、アプリのチャットに貼って送る
- **返事の決まり**：返事は JSON 1つにして中継へ返す。依頼の **`requestId`・`check`・`bot` は、変えずにそのまま返事に入れる**（変えると受け取れない・確かめられない）。終わりの返事（`reply` か、できなかったときの `error`）は1つの依頼に1通、途中経過（`progress`）は 10 通まで
- 画面に出るのは番号（`#0003`）だけ。`requestId` の後ろの乱数と `check` は、画面・お知らせ・記録には出さない（クリップボードと `pending.json` にだけ入る）
- 頼む文そのものは保存しない（字数だけを覚える）

#### 返事の確かめ
- 届いた返事は、左の UI が形を見て、覚えている依頼と比べる。`requestId` と `check` が依頼と合えば、右の欄に **「依頼と合っています ✓」** が付く。これは「この依頼への返事だ」ということだけで、中身が正しい・安全という意味ではない
- 合わないものは **灰色** で出す：check の合わない返事（確かめられない返事）・知らない依頼への返事（30 日より前・覚えていない依頼）・頼んでいない知らせ（`notice`）・知らない版の返事。灰色の返事は依頼の状態を変えず、セルも光らない。メモにすると「未確認」のタグと印が付く
- 形の読めない返事（要る項目が無いなど）・大きすぎるもの（256 KB を超える）は受け取らず、`rejected\` に回す
- 同じ返事が2回届いても、受け取るのは1回だけ。同じ依頼への2通目の終わりの返事は、1通目の下にたたむ
- 返事は外から来た文として、文字だけで出す（HTML にしない。リンクは押したときにドメインを見せてから開く。画像は読み込まない）。返事の文は2万字まで（超えた分は切って、その印を出す）
- **Markdown の表示**（S3.9）：確かめの済んだ返事（`reply`）と途中経過（`progress`）の文は、自前の小さな表示で見出し・太字・斜体・コード・コードブロック・箇条書き（2段まで）・引用・横線・表（12 列まで。崩れていたら普通の段落）・リンクを整えて出す（要素を作って文字を入れるだけで、HTML としては読まない）。**灰色の返事はそのまま**文字で出す（確かめられない返事は見た目を整えない）。エラーの文・メモの候補も文字のまま
  - 整えた返事には小さな **「元の文」** の切り替えがあり、押すとその返事だけ届いたままの文（記号もそのまま）になる。もう一度押すと戻る。メモにする・六角メモへ送る文は、いつも元の文
  - 文の中のリンク（`[文字](URL)` と生の URL）は **`http`・`https` だけ**（`javascript:` などは文字のまま）。押すと、ほかのリンクと同じくドメインを見せてから開く。画像（`![説明](URL)`）は読み込まず「画像：説明」と出す
- **回答カード**（S3.10）：確かめの済んだ返事（`reply`・「依頼と合っています ✓」）は **「Grok の回答 #0003」のカード** にする。**灰色の返事はカードにしない**（今までどおり）。途中経過・エラー・知らせもカードにしない
  - 文の中の見出し **`## 要約`**・**`## 注意`**・**`## 出典`** を探す（`#`〜`######` のどれでも。後ろの「：」は見ない。コードの囲みの中は見ない）。要約は最初の段落を **太字の1段落**（続きの箇条書きは本文へ）、注意は **⚠ の囲み**、出典は返事の `links`（無ければ `## 出典` の中のリンク。`http`・`https` だけ）を **ドメイン名のチップ** にする（押すとドメインを見せてから開く。リンクの無い出典は点線の文字だけのチップ）
  - 見出しが1つも無い返事は、全体を本文として今までどおり（Markdown の表示のまま）出す。**`## Vision` の節は本文から外す**（小さな「Vision」札のまま）。「元の文」の切り替えはそのまま
  - ボタン：**⬡ 六角メモで開く**（今の「六角メモへ」と同じ。送り先は相棒の設定で選んだノートだけ。送れたら「六角メモ『Grok-Bot』ノートに 1 マスで保存しました」とカードの下にも出す。2回は送らない）・**タブに残す**（依頼に付けたページのタブがまだ開いていれば、そのタブのメモに要約と出典を残す。無ければ右のメモへ）・**続けて聞く**（同じボットに依頼の小窓を開き、頼む文の頭に「#0003 の続き：要約の1行」を入れる。送るのは小窓から）。メモのセル・右のメモへは小さく残してある
  - 飾り：巣の設定（⚙）の「みんなに聞く」の **「回答カードに『Grok!』の札と星空（既定オフ）」** をオンにすると、カードに「Grok!」の札と星空の背景が付く（CSS だけ・画像なし・動きなし。文字の後ろには暗い下地を敷く。明るい画面でも暗い画面でも同じ星空）

#### 右のボットの欄とセルの顔
- 右サイドバーのデータ置き場の下に **ボットの欄**（受け取り箱）。右下の巣の席を1回押すか、輪の下の1行を押すか、ボットのセルのカードの「やり取りを見る」で、そのボットの待っている依頼・状態・やり取りが出る。「待つのをやめる」と、返事をメモにする（メモのセル・右のメモ・六角メモへ。メモには「ボット（名前）から届いた返事」の印）もここから
- セルの顔に状態が出る：**待っています**（点線の輪）・**作業中**（ゆっくり回る点線の輪）・**返事あり**・**遅れています**（15 分たっても返事が無い）・**ボットのエラー**（赤い枠と「!」）。右上の札はまだ読んでいない返事の数、左下は待っている依頼の数
- 頼んだ依頼への返事（check の合う、1通目の終わりの返事）が届いたときだけ、そのボットのセルが光り、相棒の吹き出しと Windows の知らせ（窓が後ろにあればタスクバーが点滅）で知らせる

#### 保存先
- `%LOCALAPPDATA%\RocksCellsBrowser\bot-inbox\`：受け取り口（動かすのはブラウザの C++ だけ）
  - `<名前>.json`：置き場から移したもの。`<名前>.taking`：取って、左の UI の答えを待っているもの（窓を開き直すと、もう一度渡す）
  - `done\`：受け取ったもの。`rejected\`：受け取れなかったもの（わけは `<名前>.reason.json`）。どちらも7日で消す。置き場での元の名前は `<名前>.source.txt`
  - 名前は依頼（`requestId`）と返事の id だけで決まる。同じ名前で中身の違うものが来たときは、`done\` の前のものを上書きせず、`<名前>-<中身のハッシュ 12 字>.json` で別に残す（中身も同じなら黙って捨てる）
- `ui-data\bots\<id>\pending.json`：そのボットの依頼（番号・check・状態・届いた返事の印。ページを付けた依頼は、回答カードの「タブに残す」でタブを探すための URL〔依頼に入れたのと同じ、? と # を消したもの〕も）。終わった依頼は 30 日残す（200 件まで）
- `ui-data\bots\<id>\log-NNNN.json`：やり取りの記録（依頼を作った・届いた返事・待つのをやめた）。1つのファイルに 100 件（か 1 MB）までで、次の番号へ。**各ボット 20 個まで**（古いものから消す。待っている依頼は `pending.json` にあるので、消しても変わらない）。`check` は記録に入れない
- どのボットか分からない返事・形の読めない返事の記録は `ui-data\bots\_unrouted\`

#### 試す
- 環境変数 `ROCKSCELLS_DATA_DIR` を指定した試しの窓は、本物の置き場（`RocksCellsRelay\inbox\`）からは返事を取らない（本物の返事を試しの窓が持っていかないように）。試しの置き場を使うときは `ROCKSCELLS_RELAY_DIR` も指定する（`<そのフォルダ>\inbox\` を置き場として見る）
  ```powershell
  $env:ROCKSCELLS_DATA_DIR = "$env:TEMP\hb-test"
  $env:ROCKSCELLS_RELAY_DIR = "$env:TEMP\hb-relay"
  .\build\Debug\RocksCellsBrowser.exe
  ```
  台帳にボットを置いてから、`$env:TEMP\hb-relay\inbox\` に `<requestId>-<id>.json`（例 `hb-20261009-0003-k3x9-r1.json`。知らせは `notice-<bot>-<id>.json`）の名前で返事の JSON を置くと、4秒ほどで受け取る。
- `npm --prefix ui run dev` の画面（C++ の代わりに偽物で動く）では、開発者ツールのコンソールで `__mockBotReply('reply')` と打つと、見本の返事が届いたことにできる
  - 見本：`reply`（返事）・`progress`（途中経過）・`error`（ボットのエラー）・`notice`（知らせ）・`badCheck`（check の合わない返事）・`unknownRequest`（知らない依頼）・`unknownVersion`（知らない版）・`broken`（受け取れない）・`markdown`（Markdown 入りの返事。見出し・表・コード・危ないリンク）・`answer`（回答カードの見本。要約・注意・出典・Vision）など（`ui/src/mock/bot-samples.ts`）
  - 見本のままだと覚えていない依頼への返事なので、灰色で届く。2つ目の引数で項目を上書きできるので、「コピーしてアプリを開く」で作った依頼の `requestId` と `check` を入れると「依頼と合っています ✓」になる（例 `__mockBotReply('reply', { requestId: 'hb-…', check: '…', id: 'r2' })`。偽物で動いているときの依頼は、開発者ツールの localStorage の `honeycomb.mockData:bots/<id>/pending.json` で見られる）
  - 右のボットの欄は、同じブラウザの別のタブで http://localhost:5173/?surface=right を開くと見られる

### コメントのスレッド（X の返信のように）
メモのセルの文章と、タブのメモ（カードの「メモを書く」・AI の要約など）の1つずつが「元のポスト」になり、その下に返信をつなげられる。拡大表示のカード（左サイドバーの下・自由に配置・右サイドバー）で使う。メモのセルのコメントは、上の「メモの分割」の下の区画でも、同じものをカードとして書く。

| 操作 | 内容 |
|---|---|
| **コメントを追加** | 元のポストに返信を書く（`Ctrl`+`Enter` で追加・`Esc` でやめる） |
| 返信の **返信** | その返信に返信する。何段でもつながる（深い段は字下げをやめて「↳ 〇〇へ」と出す） |
| **💬 n ▴ / ▾** | その下の返信を、たたむ・展開する（元のポストへの返信は、はじめから開いている） |
| **コピー** | そのコメントを、メモのセル1つとしてコピーする。盤面の空いたセルで `Ctrl`+`V`（右クリック →「貼り付け」）すると、メモのセルになる。下の返信も、そのセルのスレッドとして一緒に写る |
| **相棒 ▾** | 今の会話のメンバー（Claude・フェイブル・三人組など。右の相棒の「メンバー」）から選んで、返信を書いてもらう。「みんな」は順に書き、あとのキャラは前の返信も読んでから書く |
| **×**（2回押す） | その返信と、その下の返信を消す |

- 相棒に頼むと、スレッドの流れ（元のポスト・返信先までの道・返信先にもう付いている返信。タブのメモならページの題名と URL、スクショのメモなら撮ったページの題名〈無ければ URL〉。画像は送らない）が Anthropic に送られる。キーとモデル・練習モードは、右の相棒の ⚙ と同じ。料金はキャラのモデルの分（返信にマウスを乗せると目安が出る）
- 書いている途中は「〇〇が返信を書いています…」と出る。書きかけの返信は、カードが描き直されても残る
- 返信は元のポストと一緒に保存される（メモのセルは `ui-data\memocells.json`、タブのメモは開いているタブと一緒に）。1つのスレッドに 300 件まで
- メモのセルをコピーしたりセットにしたりすると、スレッドも一緒に写る（このブラウザの中だけ。六角メモには文章だけが渡る）
- 保存先は `ui-data\memocells.json`

### リンクを裏で開く・表紙をつけて開く（ページはこのまま）
読んでいるページから離れずに、リンクを新しいタブとして盤面のセルに足せる。足したタブは **裏で読み込んでおく** ので、押したときにはもう表示できる（そのあとは、ほかのタブと同じく自動で一時停止・休眠する）。

| 操作 | 内容 |
|---|---|
| ページのリンクを右クリック →「**セルに追加（ページはこのまま）**」 | リンクを、元のタブの隣のセルに足す（同じシート）。読み込むまでの題名はリンクの文字 |
| ページのリンクを右クリック →「**六角スクショを表紙にして、セルに追加**」 | 今のページを六角形スクショと同じ操作で切り取り（リンクの写真や見出しのまわりなど）、**表紙にしてセルに追加**。書いたひとことはタブのコメントになる |
| アドレスバーで `Alt`+`Enter` | 入れた URL（か検索）を、今見ているシートに裏で開く |
| 盤面の左上のシートの名前 ▾ →「ページのリンクから開く新しいタブ」 | **表に出す（今までどおり）**／**いつも裏で開く（セルに足すだけ）**。`target="_blank"` のリンクやページが開く新しい窓に効く。大きさや位置を決めた小さな窓（ログインなど）は、裏で開く設定でも表に出す |

- 足したセルは、しばらく太い枠で光る（どこに足したか分かるように）。ほかのシートに足したときは、お知らせにシートの名前が出る
- 表紙（切り取った六角形）は長い辺 256px に小さくして `ui-data\shots\` に保存する。見え方が「おまかせ」なら、セルに表紙が出る（「タブの見た目」）
- 右クリックの項目は、http・https のリンクの上だけに出る
- 裏で読み込んでいるタブ（表示していないタブ）が開こうとした新しい窓は、表に出さずにセルに足す。押されてもいないのに開こうとした窓（読み込みの途中やタイマーで開く広告など）は開かない
- 右クリックから足したタブも、`target="_blank"` で開いたタブと同じく、元のタブの順路の「枝」になる
- 実装：`src/tabs.cpp`（`WatchContextMenu`：WebView2 の右クリックのメニューに項目を足す。`NewWindowRequested`：裏で開く設定）、`src/browser.cpp`（`createTab` の `background`・`setLinkOpen`）、`ui/src/app/primary.ts`（`openLinkInBackground`・`linkMenu`・`startShot` の `linkCover`）

### 六角形スクショ（六角メモと同じ操作）
表示中のページを静止画にして、六角形に切り取る。`Ctrl`+`Shift`+`S`、または空いたセルを右クリック →「スクショを撮ってここに置く」。

| 操作 | 内容 |
|---|---|
| マウスを動かす | 六角形の枠がマウスに付いてくる |
| ホイール ／ `+` `-` ／ `↑` `↓` | 枠の大きさ（半径 40〜1000 px） |
| `S` ／ `1`〜`9` | 今の大きさを登録 ／ 登録した大きさにする（上のバーのボタンでも） |
| クリック ／ `Enter` | その六角形で切り取り、コメントを書く欄を出す |
| `Esc` ／ 右クリック | やめる（コメントの欄では、枠に戻る） |

- リンクを右クリック →「六角スクショを表紙にして、セルに追加」から撮ったときは、ボタンは **表紙にしてセルに追加** だけ（上の「リンクを裏で開く・表紙をつけて開く」）
- コメントを書いて（なくてもよい）：**左のセルに置く**（`Enter`。画像が顔になったメモのセル。右クリックで撮ったときはそのセルに）／**相棒に見せる**（右の相棒が画像を見て説明する。画像が Anthropic に送られる）／**両方**
- 六角形の外は透明な画像（最大 520px）。保存先は `ui-data\shots\`（撮ったページの URL と題名もメモに残る）
- 六角メモへ送るときは、画像は送らない（コメントだけ）
- `#` の右の「順路」のボタン（3つの点を線でつないだ形）で、盤面に順路の線と番号を出す・隠す（下の「順路」）

### 拡大表示（虫めがねのボタン）
マウスを乗せたタブを大きく表示する（ページのサムネイル・タイトル・番号・状態）。置き場所を選べる。

| 置き場所 | 見え方 |
|---|---|
| 下に固定 | 左サイドバーの下に常に出る |
| 自由に配置 | 盤面の上の好きな場所に置ける（上のつまみをドラッグ） |
| ポップアップ | マウスを乗せたセルのすぐ近くに出る |
| 右サイドバー | 右サイドバーに出る（自動で開く） |
| 表示しない | 出さない |

サムネイルは、表示中のタブを「読み込み終えたとき」と「サイドバーにマウスを入れたとき」に撮る。

- 「下に固定」「自由に配置」は、高さに上限があり（画面の半分くらいまで）、中をスクロールする（盤面を押し上げない）
- カードのメモ（AI の要約・解説・自分のメモ）は新しい3件。長いメモは「続きを読む ▾」（またはメモを押す）で全部、「たたむ ▴」で戻す。「ほか n 件を見る ▾」ですべてのメモ

### 六角で読む（長い文章を六角セルに組み直す）
左サイドバー上の六角形のボタン（または拡大表示のカードの「六角で読む」）で、表示中のページの本文を六角セルに組み直して、ページの上に重ねて読む。

- 分け方・並べ方は六角メモの「分けて並べる（帯）」と同じ：約70字ずつ文の区切りでまとめ、見出しは1マス、箇条書きは項目ごとにまとめる。段落は行の頭から始め、行の間をあける（「間：ふつう」は1行、「間：ゆったり」は六角メモと同じ2行）
- 本文は記事らしい所（article → main → body）から取り出し、メニュー・ヘッダー・フッターなどは除く
- **読む**：今のマスが青く光る。`→` `↓` `Space` `Enter` で次へ、`←` `↑` で前へ、`Home` `End`、マスをクリックでそこへ。`Esc` か「ページに戻る」で元の表示に戻る。下のバーに番号・今の見出し・進み具合
- **印**：`L`（またはバーの ♡）で ♥（押すたびに ♥1→♥2→♥3→なし。蛍光ペンのように色が濃くなる）。`C`（「メモ」）でマスにメモ。メモは行の間のマスに置かれる
- **AI で要点**：AI がページを読み、大事なマスを金色の枠で光らせ（3段階）、難しい語の解説を行の間のマス（青緑）に置く。`K`（「要点だけ」）で要点のマスだけをたどる
- **相棒に聞く**（`A`）：今のマスについて、右の相棒に説明してもらう（右サイドバーを閉じていたら開く）
- **六角メモへ**：♥ かメモを付けたマスを、六角メモの送り先（相棒の ⚙ で選んだノート）へ送る（タグ「ハイライト」）
- **単語帳へ**：AI の言葉の解説を、すべて単語帳のカードにする（ページの中の文を例文として付ける）。`W`（または解説の横の「＋単語帳」）で、今のマスの言葉だけ
- ♥・メモ・AI の要点・しおり（最後に読んでいたマス）は URL ごとに保存され（`ui-data\reader\`）、次に開いたときに「前回の続きから」戻る。マスは本文で見分けるので、ページが少し変わっても同じ文には同じ印が付く
- 読み進めた分は、タブの六角形の辺（読んだ量）にも反映される。最後まで読むと読了になり、相棒にも伝わる
- `−` `＋`（またはピンチ・Ctrl+ホイール）で六角形の大きさを変えられる。1行のマスの数は画面の幅に合わせる
- アドレスバーで移動したとき・戻る／進む／再読み込み・別のタブに切り替えたときは、読む画面を閉じる

### 六角で読む：YouTube の動画（区間セル）
YouTube の動画のページで「六角で読む」を押すと、字幕（文字起こし）を時刻つきの **区間セル** にして、動画の右に並べる（動画は見えたまま。区間セルプレイヤーの「セル」と同じ考え）。

- 字幕を約70字ずつ、文の区切りでまとめる。チャプターがある動画は、チャプターの名前が見出しのマスになる。マスの上に、その区間の始まりの時刻
- 再生に合わせて、今のマスが光って動く。マスを押す・`→` `←` で、その場面へ。`Space` で再生・一時停止
- **くり返す**（`R`）：今のマスの区間をくり返し再生する
- **♥ だけ再生**：♥ を付けた区間だけを、順に続けて再生する（ダイジェスト）
- ♥・メモ（`C`。「この位置でメモ」）・AI の要点と言葉の解説・単語帳へ・相棒に聞く・六角メモへ は、ふつうのページと同じ。六角メモへ送るリンクと単語帳の出典は、その場面から再生する URL（`&t=…s`）になる。印は動画ごとに保存し、次に開くと前回の続き（見始めたばかりなら、その場面へ移る）
- 「幅」で区間セルを並べる幅（420・520・640・760）、`−` `＋` でマスの大きさを変えられる（動画のときは、ふつうのページと別に覚える）
- YouTube のページの中で別の動画へ移ると、その動画の区間セルに作り直す
- 文字起こしは、YouTube 自身が取り寄せたものを読む（YouTube の印が要るので、こちらからは直接取り寄せられない）
  - 字幕（CC）を出していれば、その字幕（すぐ読める。言語は YouTube の字幕の設定で選び、「字幕を読み直す」）
  - 出していなければ、説明欄の「文字起こしを表示」の一覧を読む（読んだらパネルは閉じる）
  - それも読めなければ、字幕を一度オンにして読み、元に戻す
  - 読めないときは、YouTube で字幕（CC）をオンにしてから「字幕を読み直す」。字幕の無い動画は、下の「🎧 音声から」（ライブキャプション）で聞き取れる
- 広告の間は、区間セルは動かない（時刻のところに「広告中…」。押した場面へは、広告のあとで移る）
- YouTube のページの作りが変わると、読めなくなることがある（2026年10月の YouTube で確かめた）

#### 下に並べる・流れる表示・AI と見る
- **右に並べる／下に並べる**：区間セルを動画の右か、動画の下に並べる（押すたびに切り替え。「幅」「高さ」で大きさ）
- **流れる表示**：今のマスを下の方に出し、流れたマスは上へ動いていく。まだ流れていないマスは見せない（下に並べるときは自動でオン）
- **AI と見る：オフ／ときどき／よく**：流れた部分（ときどき＝約2分半、よく＝約1分ごと、チャプターが変わったときも）に、相棒がひとこと返す。二人目の相棒（ミツ）が会話のメンバーに入っていれば、その役割でもひとこと。ひとことは、話したマスの近くに色の付いた六角形（Claude はだいだい、二人目は青緑）で並び、動画ごとに保存される（次に見たときも出る）
  - 下のバーに「💬 Claude と見ています」「考えています…」と様子が出る
  - 料金を抑えるため Sonnet 5.5 を使う（1回 約 $0.005。1本 40 回まで）。流れた部分の字幕だけが Anthropic に送られる。練習モードではお金はかからない
  - 自分でマスを押して飛んだときは、飛ばした部分にはひとことを返さない。一時停止中・広告の間は返さない

### 六角で読む：ラジオ・自分の音声や動画のファイル
音声に合わせて区間セルが流れ、AI と一緒に聞ける。YouTube と同じ画面（右・下に並べる、♥・メモ・くり返す・AI と見る など）で使える。

- **自分のファイルを開く**：盤面の空いたところを右クリック →「音声・動画のファイルを開く…」。アドレスバーに `C:\…\番組.mp3` のようなパス（エクスプローラーの「パスのコピー」の `"…"` つきでもよい）を入れても開ける
- **画像ファイル**：空いたところを右クリック →「画像ファイルを開く…」（png・jpg・gif・webp・bmp）。セルの顔は縮図、中央は区画に合わせて縮小（クリックか Ctrl+ホイールで拡大）。「クリップボードの画像をセルにする」でも置ける。ファイルが消えていたら中央に「この画像ファイルは、もうありません」
  - 読めるファイル：mp3・m4a・aac・wav・ogg・opus・flac・mp4・m4v・webm・mkv・mov（WebView2 が再生できるもの）
- **字幕のファイルがあるとき**：「六角で読む」を押すと、同じフォルダの同じ名前の字幕（`番組.ja.srt`・`番組.srt`・`番組.vtt`・`番組.txt` など）を読んで区間セルにする。再生に合わせて動き、マスを押すとその場面へ
  - 字幕の形：SRT・WebVTT・Whisper の JSON（`segments`）・「0:05 本文」の行（YouTube の「文字起こし」のコピーなど）。UTF-8 と Shift_JIS
  - 横に無いときは、出てくる欄の「字幕のファイルを読み込む…」で選べる
- **字幕が無いとき・ラジオ**：「🎧 音声から」を押すと、Windows 11 の **ライブキャプション** が聞き取った文を、約70字ずつのマスにしていく（区間セルは流れる表示。まだ途中の文は、下に薄く出る）
  - ラジオのページ（生放送）など、どのページでも使える。流れている音なら何でも聞き取る
  - ページに再生位置のある音声・動画（自分のファイルなど）があれば、マスの時刻はその再生位置になり、マスを押すとその場面へ戻れる。生放送などでは、聞き始めてからの時刻
  - 聞き取ったマスはページ（ファイル）ごとに保存され、次に開くと並ぶ。もう一度「🎧 音声から」で、その続きに足していく
  - **AI と見る** をオンにしておくと、聞き取った部分に相棒がひとこと返す（聞き取った文だけが Anthropic に送られる。料金は動画と同じ）
  - 音声を文字にするのは Windows（パソコンの中）で、どこにも送らない。初めてのときは Windows の案内に従って、言語（日本語など）を準備する（`Win`+`Ctrl`+`L` でも開ける）。Windows 11 22H2 より前には無い
  - ライブキャプションの窓は、聞き取りをやめても開いたまま（いらなければ自分で閉じる）

### 順路（リンクをたどった道）
調べもので、リンクをたどった道を自動で覚えておき、あとで見返したり、順にたどり直したりできる（六角メモの Dendritic Extensions〈順路と枝〉と同じ考え）。

- **覚え方**：同じタブの中でリンクをたどった道が「線」、リンクを新しいタブで開いた先が「枝」。番号は開いた順。戻るで前のページに戻ったときや、同じページをもう一度開いたときは、段は増やさず「今いる場所」だけが動く
- 新しいタブ（＋）で検索を始めると、新しい順路になる。3時間あいたときや、300ページを超えたときも、新しい順路にする
- 同じページかどうかは、`#` から後ろと、広告の追跡用の引数（`utm_` など）を除いた URL で見分ける。地図を動かしたときのように、ページの中で URL だけがすぐに変わったときは、同じ段として直す
- **盤面**：順路にいるタブが2つ以上あると、タブどうしを、セルの隙間を通る順路の色の線（枝は点線）でつなぎ、セルの左上に番号を付ける。出すのは表示中のタブの順路（右の一覧で選んだ順路があれば、その順路）
- 右サイドバーの **順路** パネル
  - 表示中のタブの順路を、枝分かれの形で一覧にする（今いる段は枠、ほかのタブが開いている段は番号に輪）。段を押すと、そのページへ（順路にいるタブで開く）
  - **◀ 前 / 次 ▶**：番号の順に、1ページずつたどり直す（「最初から順に読む」で始める）。たどり直しでは段は増えない
  - **☆ 残す**（✎ で名前を付けても残る）：古くなっても消さない。残していない順路は30日で消える（1ページだけのものは1日）
  - **盤面に並べる**：順路の形のまま（線は横に、枝は下の行に）、眠ったタブとして盤面の島に並べる。もう開いているタブは、その場所へ動かす（40ページまで）
  - **AI で日誌**：題名・URL・検索の言葉・♥・自分のメモから、「調べもの日誌」（何を調べてどこに行き着いたか・流れ・わかったこと・次に調べること）を AI が書く。流れの番号を押すと、そのページへ。ページの本文は送らない
  - **六角メモへ**：順路の形のまま（1ページ＝1マス、リンク付き。日誌があれば最初のマスの左に）、六角メモの送り先のノートへ送る（タグ「順路」「調べもの日誌」）
  - 最近の順路・残した順路の一覧。押すと、その順路を開く（盤面にもその順路が出る）
  - **● 記録中**：押すと記録を止める（もう一度押すと再開）
- 相棒に「さっき調べていたページはどれだっけ」「順路を見せて」のように聞くと、相棒が順路を見て答える（道具 `list_routes`。見るだけ）
- 覚えるのは http(s) のページの URL・題名・時刻だけで、保存先は `ui-data\routes.json`（このパソコンの中だけ）。タブがどの順路のどこにいるかは、タブと一緒に `session.json` に保存される

### 単語帳と復習
覚えたい言葉や問いをカードにして、間をあけて復習する。覚えた度合いは六角形の辺で表す（六角メモの「進み具合」と同じ。6本で「覚えた」）。

- **カードの入れ方**
  - 右サイドバーの **単語帳** パネルの「＋カード」：言葉（または問い）と、意味（答え）・例文を書く
  - 相棒の返事の **単語帳へ**：「選んだ言葉を解説」の返事なら、選んだ言葉と返事が、クイズなら問題と答えが入った状態で出る（直してから入れる）
  - **六角で読む** 画面の「単語帳へ」・`W`：AI の言葉の解説から
  - **このページから作る（AI）**：表示中のページから、覚えておくとよい言葉と、理解を確かめる問いを AI が最大10枚作る。印を付けたものだけ入れる（英語のページなら、言葉は英語のまま・意味は日本語）
  - 相棒に「『〇〇』を単語帳に入れて」と頼む（道具 `add_vocab_card`）
  - **ページやセルから**：中央で言葉を選んで右クリック「単語帳のカードにする」、または Alt+クリックで出る「単語帳へ」。左のメモやページのセルの右クリックからも。入れる前に表・裏・言葉か問い・前後の文・メモを直せる（「⟳ めぐるに出す」の印も、ここで付けられる。既定は月の窓の ⚙ の「新しく入れたカードに ⟳」）。カードからページとセルへ戻れる
  - **撮影から**：右の「撮影」のカードの右クリック「単語カードにする…」。カードはその撮影の画像を指す（写さない）。表の候補は、読んだ文字の行のうち印の付いた行（無ければコメント）。撮影は 80 件までで古いものから消えるので、消えたあとは「（消えた画像）」になる
  - **下の区画のカードから**：コメントのカードの「⋯」→「単語カードにする…」。表は画面で選んでいる文（無ければ本文の頭）。カードはそのメモを出典として指し、カードに画像があればその画像も指す。元のカードは変わらない
  - 同じ言葉・問いのカードは、二重には入らない
- **復習する**：時期が来たカードを1枚ずつ（1回 50 枚まで）。`Space` で答えを見て、**1. もう一度 / 2. 難しい / 3. できた / 4. かんたん**（ボタンに次の復習までの間が出る）。`Esc` でやめる
  - 間は、覚えた度合いに合わせて 1日 → 2日 → 4日 → 1週間 → 2週間 → 1か月 とのびる。「もう一度」は度合いが2つ下がり、10分後にもう一度（その回の最後にも、もう1回出る）
  - **苦手だけ**：「もう一度」が多いカードを、時期に関係なく復習する
  - **向きと答え方**（その回だけ。保存しない）：**逆向き**（意味を見て言葉を答える。言葉のカードだけ。答えを見る前のヒントに、言葉を伏せた例文が出る）。答え方は **見る**（今までどおり）・**打つ**（打った文字と答えを並べて、違う所に印。評価は自分で付ける）・**選ぶ**（4 つから。`1`〜`4` で選び、`Space` で次へ。似たカードの答えを混ぜる。正しければ評価は付けない〈練習〉、間違えたら「もう一度」）
  - **元に戻す**：評価のあと 5 秒だけ札が出る。押すか `Z` で、そのカードの度合い・時期・回数を評価の前に戻し、答えを見た所へ戻る（最後の 1 枚なら、終えたあとの画面で戻せる）
  - 🔊：言葉のカードの表を読み上げる（このパソコンに言語の合う声があるときだけ。インターネットへは送らない）
  - カードに画像があれば、表の下に出る（逆向きのときは答えを見たあと）
  - 終わると、相棒が吹き出しでまとめを知らせる
- **知らせ**：今日復習するカードがあると、1日1回（9時から）相棒が吹き出しで知らせる（右サイドバーを開いているとき。パネルの印で止められる）
- **見出しの下**：これから 14 日に時期が来る枚数の暦（六角形）。時期を 7 日以上過ぎたカードは、一覧の六角形が褪せた色になる（枯れかけ）
- **一覧**：探す・押すと意味と例文・見つけたページを開く・直す・消す。行の頭の **⟳** で、月の窓のめぐる表示に出す印を付け外しする
  - 開いたカード：例文（中の言葉は伏せてある。押すと見える）・画像（高さ 64px まで）・メモ（500 字まで。「直す」で書く）・🔊・ページを開く・⟳ めぐるに出す／外す・🔔 復習を思い出す…（リマインダーを置く。下の「リマインダー」）・次は □ 日後…（今から 1〜365 日後に時期を動かす。度合いは変えない）・🖼 画像を付ける…・直す・消す
  - **🖼 画像を付ける…**（画像があれば「替える…」）：右の「撮影」のカードか、盤面の画像のセルを選ぶ。画像は写さず指すだけ。**画像を外す** で外れる
  - **セルを登録…**：開いたカードに、左の盤面のタブかメモのセルを登録する（名前で探して選ぶ）。**＋ セルを足す…** で 6 つまで。同じセルは二重に入らない。1 つ目は「出典」、2 つ目からは「関連」の札が付き、札を押すと 役目なし → 出典 → 関連 と回る。**×** で 1 つ外す
  - **セルへ**：そのセルのあるシートに移り、セルに印が付いて見える所まで動く。メモなら、下の区画でも開く。セルが消えていたら、カードは残ったまま「そのメモのセルは、もうありません」（タブなら「そのタブのセルは、もうありません」）と1行出る。タブのセルで、そのタブのページがカードの出典と違うときは、横に「ページを開く」
  - 登録はカードの項目として `ui-data\vocab.json` に足すだけ（今までのカードの中身はそのまま。古い版のための 1 つ目の写しも残す）。月の窓のめぐる表示のカードには、先頭のセルが「セルへ：題名」で出る
- **左の盤面のセルから**：タブかメモのセルの右クリック「つながったカード n 枚を見る」で、右の単語帳がそのセルのカードだけに絞られる（札の「絞りを外す」で戻る）。「このセルのカードを ⟳ に出す」で、まとめて ⟳ の印を付ける（つながったカードが無ければ、どちらも出ない）
- **六角メモへ**：まだ送っていないカードを、六角メモの送り先のノートへ送る（タグ「単語帳」。覚えた度合いは六角形の進み具合として付く。印を付けると、次の復習日を期限として付けるので、六角メモの期限の一覧と通知にも出る）。送ったあとの復習は六角メモには反映されない（写しを送るだけ）。メモと画像は送らない
- 相棒に「今日の復習は？」「苦手な言葉は？」と聞くと、単語帳を見て答える（道具 `vocab_status`）
- 保存先は `ui-data\vocab.json`（このパソコンの中だけ）。AI でカードを作るときだけ、ページの文章が Anthropic に送られる（メモと画像は AI に渡さない）
- 台帳が読めなかったとき（壊れている・形が違う）は、3 秒後に 1 回読み直し、それでも読めなければその起動では書かない（上書きして失わないため）。盤面に知らせが出て、単語帳の区画に帯が出る。閉じる直前にも、待っている分を書いてから閉じる
- 古い版のアプリに戻すと、カードの ⟳ の印・メモ・2 つ目からのセル・画像は、古いアプリがカードを書き直したときに消える（古い版は知らない項目を捨てる。1 つ目のセルは残る）。試すときは `ROCKSCELLS_DATA_DIR` で試し用のデータフォルダを使う

### リマインダー（右サイドバー）
決めた時刻か、決めたきっかけで知らせる。相棒に頼んでも、自分で置いてもよい（右サイドバーの「リマインダー」の区画）。

- **＋リマインダー**：文の頭に「30分後」「2時間後」「今夜」「今日の夕方」「明日の朝」「明日9時」「来週」「10/25 14:30」と書けば、その時刻になる（残りが文）。押しボタン（10 分後・1 時間後・今日の夕方・明日の朝・来週）と時刻の欄でも選べる
  - **繰り返し**：なし・毎日・毎平日・毎週・毎月。鳴ったら、同じリマインダーが次の回に置き直される（毎月で、その日が無い月は月末）。閉じている間に何回も過ぎていても、鳴るのは 1 回
  - **いつ知らせるか**：時刻／次に（今のタブのサイト）を開いたとき／次に起動したとき。きっかけのものは時刻では鳴らない。サイトは、別のサイトからそのサイトへ移ったとき・そのサイトのタブに切り替えたときに鳴る（1 回きり）
  - **今のタブに結ぶ**：押すと、そのタブのセルへ移れる
- **行**：日ごとの見出しの下に、時刻と残り・文・きっかけの札・指す先の札（押すとそのセルへ）・置いた人の印（金の六角＝相棒、灰の六角＝自分）・↻（繰り返し）・⏲（10 分・1 時間・今日の夕方・明日の朝へ延ばす）・✓（済み。繰り返しは次の回へ）・×（取り消す）。✓ と × のあと 5 秒だけ「元に戻す」
- **鳴ったとき**：Windows の通知と、相棒の吹き出し（「10 分延ばす」「1 時間延ばす」「そのセルへ」「済み」。単語カードから置いたものは「単語帳で開く」）。ブラウザを閉じている間に過ぎたものは、次に起動したときに知らせる
- **鳴ったもの**：区画の下の列。鳴った・済み・延ばした・取り消したを、新しい順に 50 件まで残す。行の ✓（済み）・⏲・「カードに」（単語帳の「＋カード」を、その文で開く）・「もう一度」（同じ文で置く欄を開く）
- **単語カードから**：開いたカードの「🔔 復習を思い出す…」で、「復習：表」のリマインダーを時刻か「次に起動したとき」で置く
- **上限**：時刻のものは 100 件、きっかけのものは 30 件。いっぱいなら「リマインダーがいっぱいです」と出て置かない
- 右の「検索」で ⏰ として探せる。月の窓のめぐる表示にも映せる（下の「月の窓」）
- 保存先は `ui-data\reminders.json`（置いてあるもの）と `ui-data\reminders-fired.json`（鳴ったもの）。どちらも、読めなかったら単語帳と同じく書かない（区画に帯が出る）
- 古い版のアプリに戻すと、繰り返しは 1 回だけ鳴って終わり、きっかけのもの（サイト・起動）は鳴らない（置いた時刻の 400 日後まで鳴らない形にしてある）。鳴ったものの記録は使われない

### いいね・メモ・読んだ量
- **♡ / ♥**（拡大表示のカード）：押すたびに ♥1 → ♥2 → ♥3 → なし。セルの下に ♥ が付く
- **メモを書く**：そのページのタブに自分でメモを残す（Ctrl+Enter で残す・Esc でやめる）。AI の返事を「タブに残す」と同じ場所に並ぶ
- **読んだ量**：表示中のページをどこまでスクロールしたかを、セルの六角形の辺で表す（6辺で読了。最後まで読むと辺の色が変わり、リストでは「読了」）

### タグと島（整理）
- **タグ**：拡大表示のカードの「＋タグ」で付ける（Enter）・× で外す。カードの下の **タグのボタン**（6つ）なら押すだけで付く（次の節）。決まりは六角メモと同じ（先頭の # と空白は取り除く。1つに10個まで）。六角メモに登録してあるタグは、同じ色で出る。リストの表示では、タイトルの横に3つまで出る
- **島**：盤面でタブをひとかたまりにまとめ、六角メモの「領域」と同じように色の枠と名前で囲む。島を作ると、入るタブがひとかたまりのセルへ寄る（ほかのタブは動かない。島どうしは1マスあく）。カードの「島：名前 ×」で、そのタブを島から出せる
- 右サイドバーの **整理（タグと島）** パネル
  - タグの一覧（数つき）。押すと、そのタグのタブだけを盤面で目立たせる（もう一度押すと戻る）
  - **AI でタグを付ける**：開いているタブのタイトル・URL・メモから、タグの案を作る（なるべく六角メモの登録済みのタグから選ぶ。答えは六角メモと同じ `hexmemo-tag-result` の形）。印を外したものは付けない
  - **AI で島を提案**：近い内容のタブを島に分ける案を作り、盤面に「まとめた後の形」を点線で見せる。「島にする」で反映
  - **急がない**：バッチで頼む（料金が半額。数分〜1時間ほどかかり、終わるとパネルに案が出る。ブラウザを閉じても、次に開いたときに受け取る）
  - 島の一覧と「解散」（タブはそのまま）
- 相棒に「この2つを『調べもの』の島にまとめて」「このタブに『重要』タグを付けて」のように頼むこともできる
- AI に案を頼むと、タブのタイトル・URL・タグ・メモ（短く）が Anthropic に送られる。反映は、使う人が「タグを付ける」「島にする」を押したときだけ

### タグのボタン（6つ・セット・その他）
よく使うタグを6つのボタンにして、押すだけで付けたり外したりできる。拡大表示のカード（タブ・メモのセル。左は「下に固定」「自由に配置」、右は「右サイドバー」に置いたとき）の、タグの列の下と、右の「メモ」の区画の「選んだコメントのタグ」に出る。

| 操作 | 内容 |
|---|---|
| ボタンを押す | そのタグを付ける。付いているタグのボタンは濃い色と ✓ になり、もう一度押すと外す |
| 空いたボタン（＋）を押す | そこに登録するタグを選ぶ（新しいタグを書く・このタブやメモのタグ・よく使うタグ・六角メモのタグ） |
| ボタンを右クリック | 付ける／外す・← 前へ・後ろへ →・別のタグに替える・ボタンから外す（付けたタグはそのまま） |
| セットの名前 ▾ | タグのボタンのセット（6つで1組）を切り替える。新しいセット・このセットを複製・名前を変える・消す（2回押す。最後の1つは消せない）。12 個まで |
| その他 ▾ | 6つのボタンに入っていないタグ（付いているもの → 使っている数の多い順 → 六角メモのタグ。60 個まで）。それぞれ「付ける／外す」と「ボタンへ」（空いたボタンに登録）。いちばん上の「＋ 新しいタグを書いて付ける…」 |
| ✎ | 使っているセットの名前と6つのタグを書き直す（↑↓ で並べ替え・「空に」。Ctrl+Enter か「保存」で決める） |
| 左上の ▾ | タグのボタンをたたむ（左右それぞれ覚えておく） |

- セットは相棒の6つのボタンと同じ考え：切り替えると6つのボタンが入れかわるだけで、付いているタグは変わらない。同じタグをいくつのセットに入れてもよい
- 左サイドバーと右サイドバーは、別々のボタンとセットを持つ（左はタブのセルと盤面のメモのセル、右はコメントと右のカード。セットの名前 ▾ のメニューの見出しに、どちらのものかが出る）。保存先は `ui-data\tag-buttons-left.json`・`ui-data\tag-buttons-right.json`
- 右のコメントのタグは、そのメモのセルのタグと同じもの（左の盤面のカードでも見える・変えられる）。ポップアップの小さいカードには、タグだけが出る

### 検索（右サイドバー）
右サイドバーの「受け取り箱」の下、「タグごとの一覧」のすぐ上。メモ・コメント・タブ・撮影・データ置き場・単語帳を字で探して、1 本の一覧にする。

- **字**：空白で区切った語を、すべて含むものを出す。全角・半角、大文字・小文字、カタカナ・ひらがなの違いは気にしない（`ｶﾞｲﾄﾞ` も「がいど」で当たる）。語の先頭の `#` は外す（タグも探せる）。字を打つと少し待って探す。Enter ですぐ探し、Esc で字を消す。当たった所の前後を、印を付けて出す
- **並べ方**：新しい順（作った時刻）／更新順。メモの「更新」は、本文・タグ・♥・画像の変更と、コメントのカードを足した・書き直した時刻の新しいほう（下の区画の一覧やタグごとの一覧の「最近」はカードを数えないので、検索だけ少し意味が違う）。撮影・データ置き場・単語帳には更新の時刻が無いので、どちらでも作った時刻（置き場は置き場に入れた時刻）
- **タブ**は時刻を持たないので、時刻のあるものの下にまとめる（その中は、今の起動で最近見た順）
- **対象**：「メモ」（コメントを含む）・「タブ」・「撮影」・「置き場」・「単語帳」のボタンで選ぶ（はじめは全部。少なくとも 1 つ）。選んだものと並べ方は、このパソコンに覚える（字は覚えない）
- **字が空**のときは、選んだものの最近の一覧（タブは出さない）
- 30 件ずつ出す（「ほか n 件を見る」で足す。300 件まで）。もう無いものの行は薄くなり、押すと知らせる。読み込み中のもの（撮影・データ置き場・まだ届いていない写し）があれば、状態の行に出す
- メモやコメント、ほかの区画の中身が変わると、少し待って探し直す

| 対象 | 探すところ |
|---|---|
| メモ | 本文・タグ |
| コメント | カードと返信の文・引用の文・引用元の題名 |
| タブ | 題名・URL・タグ・ひとこと・タブのメモとそのコメント |
| 撮影 | ひとこと・ページ名・スタンプの一行・線の文字・読んだ文字（チェックを外した行・隠した行・表の追加の行は探さない。ページの本文の写しも探さない） |
| データ置き場 | 目次だけ：題名・はじめの 160 字・タグ・ページ名・話した人・トピック（会話の途中の言葉は当たらない） |
| 単語帳 | 言葉・問い、意味・答え、例文、ページ名 |

盤面のシートへの入口・ボット・アプリのセルは出さない。撮ったもののセルはメモとしては出さず、「撮影」として出る。

- **押すと**：メモは下の区画で開く。コメントは、そのメモを下の区画で開いてそのカードへ移り、少し光らせる（返信なら木をたどって開き、長い文は全文を開く）。メモとコメントの行の「盤面で見る」で、左の盤面のそのセルへ移る。タブはそのページを表示する。撮影・データ置き場・単語帳は、その区画を開いてそのカードを出す
- 下の区画に書きかけ（コメントの欄・カードの書き直し・返信の欄）があるときは、右の検索から別のメモは開かず、「書きかけがあります」と知らせる（同じメモの中なら移れる）
- 台帳は読むだけ（何も書き換えない）。外へは送らない。▾ でたたむ（覚えておく）。見出しの右クリックで上のタグに登録できる

### タグごとの一覧（右サイドバー）
右サイドバーの「検索」の区画のすぐ下。タグごとのまとまりに、そのタグの付いたタブ（ページ）とメモのセルを並べる（2つのタグが付いていれば、両方のまとまりに出る）。

- **まとまり**：右のタグのボタンの順／左のタグのボタンの順／数の多い順。ボタンの順のときは、ボタンのタグ（まだ何も付いていなくても出る）→ その他のタグ（数の多い順）→ タグなし
- **並べ方**（まとまりの中）：盤面の番号順（シートの順、その中の番号）／最近使った順／名前順。タブが先、メモのセルが後
- タブを押すと、そのページを表示する（左の盤面も、そのタブのシートへ）。メモを押すと、左の盤面がそのシートに移り、そのセルに印を付けて見える所まで動かす（拡大表示を「下に固定」「自由に配置」にしていれば、カードにも出る）
- 見出しを押すと開く・閉じる（覚えておく。はじめはボタンのタグだけ開く。ボタンのタグが無ければ、上から3つ）。12 件より多いときは「ほか n 件を見る」
- 見出しの **◎**：そのタグのタブだけを、左の盤面で目立たせる（整理パネルのタグと同じ。もう一度押すと戻る）
- ▾ で一覧をたたむ（覚えておく）

### 右サイドバー（四角のボタン）
上から順に、「パネル」の見出しと上のタグ（登録した区画へ飛ぶボタン）、月の窓。その下の欄に、メモ → データ置き場 → 撮影 → 合図 → 受け取り箱（ボットの欄。「ボットの返事を受け取る（第2段）」） → 検索 → タグごとの一覧 → 拡大表示 → 順路 → 単語帳 → 情報収集 → 整理（タグと島） → 相棒が覚えていること → 休眠 → リマインダー → これからの区画。いちばん下に AI の相棒、そのすぐ下に Grok Bot（6体まで。「右下の Grok Bot」の節）。これから追加するパネルの置き場所でもある。開いているかどうかも次回に引き継ぐ。

### 右サイドバーの見出し（たたむ・上のタグ）
右サイドバーの各区画は、見出しの **▾** でたためます（**▸** で開く）。メモ・データ置き場・撮影・受け取り箱・検索・タグごとの一覧・月の窓は、それぞれの ▾ です。合図・拡大表示・順路・単語帳・情報収集・整理・相棒が覚えていること・休眠・リマインダー・これからの区画・相棒も、同じようにたためます。相棒をたたむと、その下の巣もいっしょに隠れます。たたんだことはこのパソコンに残り、次に開いても戻ります。

見出し（題名のあたり）を右クリックすると、「タグ1に登録」から「タグ6に登録」と「その他…」が出ます。登録した区画は、「パネル」のすぐ下にボタンで出ます（登録するまでは、登録の仕方の1行だけ）。ボタンを押すと、閉じていても開き、そこまで動きます。同じ区画は1つのタグにだけ入ります。別の区画を同じ番号に登録すると、前のものは外れます。まだ何も登録していない番号のボタンは出ません。

「その他…」は、登録していないものも含めた、全部の区画の一覧です。名前を押すと、そこへ動きます。月の窓は、出すレターも Vision も無く、めぐる表示も切っているときは隠れています。そのときタグから飛んでも、窓は出ません。めぐる表示を入れていれば、レターが無くても出ます。

### 自動休眠
使っていないタブは、時間がたつと自動で眠ってメモリを空ける。

| 状態 | いつ | 中身 | 見た目 |
|---|---|---|---|
| 待機中 | 切り替えた直後 | 裏に隠れているだけ | ふつうのセル |
| 一時停止 | 5分使わなかったら | ページの動きを止めて、メモリを減らす。すぐ戻れる | 少し沈んだセル |
| 休眠 | 25分使わなかったら | ページを閉じて URL だけ覚える。開くと読み込み直す（スクロール位置も戻る） | 点線の枠 |

- 眠らないタブ：表示中、音が出ている（セル右下の ♪）、「休眠させない」にしたもの（セル左下の点）
- 入力途中の文字があるタブは、消えないよう一時停止のまま休眠を保留する
- 拡大表示のカードのボタン：「休眠させない / 休眠を許可」「今すぐ休眠」「ミュート」
- 時間は右サイドバーの「休眠」パネルで変えられる（状態ごとのタブの数も出る）
- 休眠したタブは「戻る」の履歴が消える（WebView2 の制限）

### AI の相棒（右サイドバーのいちばん下の六角形）
右サイドバーの下に Claude が常駐する。六角形を押すと会話が開く・閉じる。
待機中はまばたき、考えている間は目が動いて枠が流れ、話している間は口が動く。

- 最初に ⚙ から **API キー** を保存する（Windows の DPAPI で暗号化して `%LOCALAPPDATA%\RocksCellsBrowser\ai-key.bin` に置く。同じ Windows ユーザーでしか読めない）
- 入力欄の上に **6つのボタン**（`Alt`+`1`〜`6` でも押せる）。はじめは **ページを要約**／**言葉を解説**（ページで文字を選んでから）／**クイズ**（答えは「答えを見る」まで隠す）／要点を3つ／やさしく／別の見方
  - **セット**：6つで1組のボタンを、いくつでも作って切り替えられる（左上の「いつもの ▾」。はじめは「いつもの」と「学ぶ」）
  - **その他 ▾**：6つに入りきらない文言の一覧。押すと相棒に送る。入力欄に書いた文を「＋ 入力中の文を登録」でそのまま足せる
  - **✎**：ボタンとその他の文言を編集する。1つずつ、表示名・押したときにすること（文言を送る／入力欄に入れる〈続きを書いてから送る〉／要約／解説／クイズ）・文言・「ページを添える」を決める。セットは新しく作る・複製・消す・名前を変える。空いたボタン（＋）を押しても、その欄から編集できる
  - 文言を送るボタンは、入力欄で話しかけたのと同じ（「Claude へ／フェイブルへ／みんなへ」などの宛先も効く）。保存先は `ui-data\phrases.json`
- 入力欄で話しかける（Enter で送る・Shift+Enter で改行）。「このページについて」に印があると、表示中のページを添えて聞く。返事の途中で「止める」も押せる
- ページの文章を送るのは、ボタンを押したり話しかけたりしたときと、下の「相棒から話しかける」とき（本文は最大4万字・タイトル・URL・選んだ文字）。同じページの同じ本文は、同じ会話の中では1回だけ送る
- 返事ごとにトークン数と料金の目安、会話全体の合計を表示する
- モデルは Claude Opus 5.5（標準）と Claude Sonnet 5.5（速い・安い）から選べる（賢者のフェイブルは Claude Fable 5.1、ソネット三人組は Claude Sonnet 5.5 で決まっている）
- **練習モード**：API を使わずに、画面の動きだけ試せる（料金なし）
- **会話の保存**：1往復ごとに自動で保存する（`%LOCALAPPDATA%\RocksCellsBrowser\ui-data\conversations\`）。次に起動すると最後の会話から続く。「履歴」で過去の会話を開き直したり（続きから話せる）、消したりできる。「新しい会話」でいつでも最初から

### 相棒から話しかける（出来事）
ブラウザで起きたことに、相棒が自分からひとこと話す。会話を閉じているときは、六角形の上に吹き出しで出る（押すと会話が開く・15秒で消える・マウスを乗せている間は消えない）。

| ⚙ の「相棒から話しかける」 | 話すとき |
|---|---|
| 話しかけない | 話さない（頼まれたときだけ） |
| 控えめ（標準） | ページを最後まで読んだとき（95% までスクロールして、20秒以上たったら。同じページでは1回だけ） |
| ふつう | それに加えて、♥3 を付けたとき・メモを書いたとき |

- 1日に自分から話す回数には上限がある（標準20回。⚙ で 1〜200 回）。今日の回数も ⚙ に出る
- 話している最中に起きた出来事は、話し終わってから話す（いちばん新しい1つだけ・2分以内）
- 右サイドバーを閉じているときは話さない
- 会話には「このページを読み終えました」などの小さな1行と、「ひとこと」の返事として残る（タブや六角メモにも残せる）

### 会話のメンバー（Claude も入れて3枠まで）
会話には、Claude も入れて **3枠まで** の AI のキャラクターが同時に参加できる（ハイク組は何体でも1枠）。会話のいちばん上の名前（▾）を押すと、メンバーを選ぶ欄が開く。右下には、メンバーの六角形の顔が並ぶ。

| キャラ | モデル | どんな役 |
|---|---|---|
| **Claude**（だいだい） | ⚙ で選ぶ（Opus 5.5 / Sonnet 5.5） | いつもの相棒。ブラウザの操作・Web 検索・出来事への反応 |
| **ミツ**（青緑・葉っぱ） | ⚙ で選ぶ | 二人目の相棒。役割を ツッコミ・別の視点（標準）／学習サポート／盛り上げ役 から選ぶ |
| **フェイブル**（紫・眼鏡と三日月） | Claude Fable 5.1（いちばん賢い） | 博識な賢者。じっくり考えて本質を突き、みんなの話をまとめ直したり、一段深い問いを投げたりする。料金は Opus 5.5 の約2.5倍（入力 $10・出力 $50 / 100万トークン） |
| **ソネット三人組**（触角のある3体） | Claude Sonnet 5.5 が3体 | 性格の違う三人組。**ルカ**（黄・好奇心いっぱいの質問役）、**ジン**（青・慎重で辛口の確かめ役）、**モモ**（ピンク・やさしい実践役） |
| **ハイク組**（右上に短冊・頭に季語の飾り） | Claude Haiku 5.5 が3〜6体（いちばん安い） | 係の違う組。**ツクシ**（見る係・土筆）、**ホタル**（調べ係・光の玉）、**モミジ**（まとめ係・紅葉）、4体目 **ユキ**（確かめ係・雪の結晶）、5体目 **カエル**（記録係・飛び出した目）、6体目 **トンボ**（見回り係・透明な羽）。何体でも会話のメンバーの **1枠** |

- 考える深さ（effort）：フェイブルと三人組は high、Claude とミツは medium。high は考える量が増えるぶん、返事が少し遅く、料金も少し増える（コメントのスレッドへの返信も同じ）
- メンバーの欄で印を付け外しする。4枠目を選ぶと「3枠までです」と出る（先にだれかを外す）。1体は残す
- **三人組で話す**：メンバーを三人組の3体にして、宛先を「みんなへ」にする（ほかのキャラは外れる）
- **ハイク組**：メンバーの欄の、三人組の次の区画。印を付けると組が入り（1枠）、横の選択で人数（3〜6体）を選ぶ。**ハイク組で話す** で、メンバーをハイク組だけにする。宛先には **ハイク組へ** が出る（組の中のひとりへは、顔を押す）
  - 3体までは、「ハイク組へ」「みんなへ」で全員が順に答える
  - 4体からは ⚙ の「ハイク組」で話し方を選ぶ：**モミジが代表**（モミジだけが組を代表して答える。顔の枠が金色）／**2つの班が順番に**（4体なら2・2、5体なら3・2、6体なら3・3の班が、頼みごとごとに交代で答える）。掛け合いも同じ
  - 班の順番は、「ハイク組へ」「みんなへ」と掛け合いで別々に回り、班のだれかが答え終えたときだけ次の班へ進む（会話といっしょに保存。履歴から開き直しても続きの班から）
  - コメントのスレッドの「返信を頼む」でも、ハイク組は「ハイク組」の1つ（3体までは全員、4体からはモミジか最初の班が返信する）
  - 道具：ツクシはタブと順路を見てほかのタブを読む、ホタルは Web 検索、モミジはリマインダーと単語帳（確認してから）、カエルは考察を残す（確認してから。タブの一覧も見る）、トンボはタブと順路を見る、ユキは話すだけ
  - 料金は Opus 5.5 の約40分の1（10万トークン以下なら 入力 $0.10・出力 $0.50 / 100万トークン）。考える深さは medium
  - **先生への相談**：ハイク組の体は、自分だけでは自信が持てないところだけ、**Claude 先生**（Opus 5.5）か **フェイブル先生**（Fable 5.1）に相談できる（道具 ask_advisor。1つの頼みで組全体で1回まで）。アプリが「相談の手紙」（問い・理由・使う人の頼み・最近の会話・ページの一部）を作って先生を1回きりで呼び、助言は返事の中の **助言カード** に全文が出る（［相談の手紙を見る］で渡したものも見られる。［役に立った］［外れた］で効き目を記録）。助言はハイクに情報として渡り、会話の記録にも残る
  - 許可は先生ごとに ⚙ で：毎回聞く／この会話ではいつも（最初の1回だけ聞く。Claude 先生の標準）／相談しない。フェイブル先生は標準で毎回聞く。許可の欄には、渡すもの（問い・理由・使う人の頼み・最近の会話の行数・ページの題名と字数。フェイブル先生なら30日保存のことも）と料金の目安が出る。30秒で答えがなければ、相談せずに続ける。見送った（やめる・答えなし）頼みでは、ほかの体ももう許可を聞かない
  - **先生に聞く**：ハイク組に話しかけるとき、入力欄の上に「先生に聞く：✦ Claude ／ 🌙 フェイブル」（数は今日の残り）が出る。押すと、ハイク組が答える前に先生に相談する（押す＝許可）。入力が空なら、先生には「ハイク組が次に答えるときに気をつけること」を聞いて、組には続きを頼む。相談できなかったときは、ハイクにも「助言は無い」と伝わる
  - 枠はハイク組だけの1日の回数（✦ きらり＝Claude 先生 10回、🌙 月＝フェイブル先生 3回。⚙ で変えられる。フェイブルの進化とは別）。0時に戻る。先生が書き始める前に届かなかった相談（つながらない・断られた・空）の分は戻るが、時間切れ（Claude 先生 90秒・フェイブル先生 4分）と［止める］は使ったことになる（途中までの料金がかかることがあるため）。先生の返事は考える分も含めて8千トークンまで（切れたら、カードとハイクに「途中まで」と伝える）。1回の目安は Claude 先生 約 $0.02〜0.10、フェイブル先生 約 $0.05〜0.25。返事の下の料金に「うち相談」が出る（ハイクの返事が失敗しても、相談の分は数える）
  - Anthropic に送るもの：相談の手紙（ページの文章は6千字まで）。フェイブル先生（Fable 5.1）は、データの30日の保存が条件のモデル
- 入力欄の上で、話しかける相手を選ぶ：**〇〇へ**（ひとりへ）／**二人へ・みんなへ**。顔の六角形を押しても、そのキャラ宛てになる（もう一度押すと会話を閉じる）
- 「みんなへ」は、メンバーの順に答える。あとのキャラは、先に答えたキャラの返事も聞いたうえで答える
- **掛け合い**（⚙）：だれかが答えたら、ほかのメンバーが順にひとことずつ返す（付け足すことがなければパスする）。クイズには入らない。返事の回数が増えるので、料金も増える
- ブラウザの操作（タブを開く・閉じる・休眠・音楽など）は Claude だけ。Claude がメンバーにいない会話では、要約・解説・クイズなどの頼みごと、出来事への反応、六角で読む画面などからの「相棒に聞く」には、いちばん上のメンバーが答える
- ほかのキャラも、性格に合わせて少し道具を持つ（⚙ の「ブラウザの操作を任せる」「Web 検索を使う」が入っているとき。キャラがその会話で初めて話すときに決まり、その会話の間は変わらない＝前の部分の読み直しの割引が切れないように）：

| キャラ | 道具 |
|---|---|
| フェイブル | ほかのタブの本文を読む（いくつかの記事を比べて考える）・タブの一覧・順路・覚えていること・単語帳の様子・情報収集のトピックを見る・Web 検索・Web のページの取得・考察を残す（メモのセル／タブのメモ／メモのスレッドへの返信。**確認してから**） |
| ジン | Web 検索（事実を確かめる） |
| ルカ | タブの一覧・順路を見る（見るだけ） |
| モモ | リマインダーを置く・単語帳にカードを入れる（**確認してから**） |
| ミツ | なし（話すだけ） |

- Anthropic に送るもの：道具を使ったときの結果（タブの一覧＝題名・URL・メモ、読んだタブの本文〈2万字まで〉、順路・覚えていること・単語帳・トピックの様子）。Web 検索と Web 取得は Anthropic 側で行う（Web 検索は1回 約 $0.01、Web 取得は読んだ分のトークンだけ）
- 確認してから使う道具は、確認の中に、残す文・置くリマインダー（時刻つき）・入れるカードを全部見せる。メモのセルに残した考察には「考察・フェイブル」の印が付き、そのメモのスレッドで相棒に返信してもらうときも「AI の考察」として渡す
- 会話の途中で ⚙ の「Web 検索を使う」を切ると、Claude はすぐ検索しなくなる。すでに話したキャラ（フェイブル・ジン）は、その会話の道具の一覧は変えずに「使わないで」と毎回頼む（確実に止めたいときは、新しい会話にする）
- 名前と性格（性格は自由に書ける）は ⚙ の「キャラクター」で変えられる。「元に戻す」で最初の設定に。名前・性格・ミツのモデルを変えると、そのキャラがまだ話していない会話から効く（話し始めた会話では、途中で変えない。モデルを途中で変えると、考えた跡と前の部分の読み直しの割引が使えなくなるため）
- キャラはそれぞれ自分の会話の流れを持ち、ほかのキャラや使う人の発言は「自分が話していない間にあったこと」として、次に話すときに添えて渡す（だれの履歴も書き換えない。途中から加わったキャラも、最近のやりとりを聞いてから話す）。会話の保存・履歴からの開き直しにも、全員の分が入る（前の形で保存した二人の会話も、そのまま続きから話せる）
- 「AI と見る」（YouTube・ラジオ）のひとことは、Claude と、メンバーに入っていればミツが返す
- Grok など別の会社の AI を相棒にするには、その会社の API を別に用意してつなぐ必要がある（今は Claude どうし）。Grok Bot アプリのボットは相棒ではなく、外のアプリへの窓口として「ボットのセル」と「右下の Grok Bot」から開く

### 右下の Grok Bot（右サイドバー。任意のボット連携）
右サイドバーのいちばん下、相棒（Claude・ミツ・フェイブル・ソネット三人組など）の並びのすぐ下に、**六角形の輪（巣）** がある。席は6つまで。盤面のボットのセルと同じ台帳を使う。ここは細い1列ではない。

輪にたどり着くには、右サイドバーを開き、下までスクロールする。相棒の顔の並びのすぐ下が巣。

| 操作 | 内容 |
|---|---|
| 空いた席の ＋ | 台帳のボットを置く。または「新しいボット（リンクか id を貼る）」で、Grok Bot アプリの「リンクをコピー」を貼ってから置く。**6体いるときは置けない**。どれかを右クリック →「右下から外す」と、席が空く（台帳には残る） |
| 席を1回押す | そのボットを選ぶ。輪の下に名前と **この子に頼む** が出る。アプリは開かない。右のボットの欄には、そのボットのやり取りが出る |
| 席をダブルクリック | Grok Bot アプリの、そのボットのチャットを開く。はじめての1回だけ「外のアプリを開きます」と確かめる。リンクが無い席は開かず、右クリック →「リンクを貼る…」と出る |
| 右クリック（Shift+F10） | Grok Bot アプリで開く・コピーしてアプリを開く…・リンクを貼る（貼り直す）・名前を変える・前の席へ・次の席へ（Alt+← →）・右下から外す |
| **この子に頼む** | 依頼の小窓が開く。宛て先はこのボット。頼む文を書いてから **コピーしてアプリを開く** を押すまで、クリップボードもアプリも動かない |
| **⬡ みんなに聞く（n体）** | 同じ小窓が、宛て先「みんな」で開く。送り方は巣の ⚙ の「みんなに聞く」（1体ずつ案内／代表にまとめて） |
| **グループに頼む ▾** | 5つのグループから選ぶ。小窓の宛て先は「グループ：まとめる・調べる（2体）」のようになり、役のボットへ1体ずつ「コピーしてアプリを開く」で貼る。頼む文の頭は、グループで受け持つ役（細かい設定は既定）。まとめ役がいる組は、受け取り箱の組のカードから「まとめ役に渡す」 |
| 輪の下の1行 | 「Grok Bot：待っている依頼 …」。押すと **受け取り箱**（右のボットの欄の、依頼の一覧）へ移る |
| 巣の ⚙ | 並び・役・みんなに聞くの設定。依頼の小窓が開いているあいだは開かない。「役」タブの上の **席の役／グループ** で、5つのグループ（役ごとのボットとまとめ役）を登録する画面に切り替わる |

- **依頼の小窓**は、巣の上に重なる。中身は上から、**送るもの**（ページの URL・題名・選んだ文・本文のカード。押して外す。外したものはどこにも入らない。本文ははじめは外す。選んだ文と本文は見えない文字〔制御文字・向きの文字〕を消し、消した数をカードに出す）、定型、頼む文、役の文、宛て先、返し先、**送る前の 1 行**（宛て先｜付けるもの｜字数〔役・自分・添えたもの／2 万字〕｜返し先。打ちながら更新され、前回コピーした依頼〔無ければ開いたとき〕から変わった所に色が付く）。頼む文が空でも、選んだ文・本文・画像のどれかを付けていれば送れる（役が補う一文「選んだ文について調べてください。」などが頼む文になる）。何も付けていなければ送れない（みんなに聞く・グループは文が要る）。「やめる」か Esc で閉じる。閉じただけでは依頼はできない。コピーしてアプリが開いたものだけ、受け取り箱に番号が付く
- **鍵らしき文字の見張り**：付けた選んだ文・本文と頼む文に、鍵らしき文字（`sk-ant-`・`xai-`・`AKIA`・`api key`・`PRIVATE KEY`）があると、送る前の 1 行の上に赤い帯が出て送れない。「〔鍵1〕に置き換えて送る」で印に置き換える（元の値は残さない）か、「選んだ文を外す」（本文なら「本文を外す」）まで、コピーのボタンも Ctrl+Enter も効かない。カードの見本は伏せた文で見せ、閉じて下書きに残すときも置き換える。画像の中はまだ見ない
- 依頼（と六角スクショの画像）は、Windows の**クリップボード履歴（Win+V）とほかの端末への同期に入れない印**を付けてコピーする（小窓の足に小さく出る）。六角メモ・相棒のコピーは今までどおり
- **役の文**：依頼の頭に入る役の文が、頼む文の下の欄に見える（用意した役の終わりには「はじめに、一行の答え・次の一手・どのくらい確か、を書く。」が入る）。直すと「今回だけ」（台帳の役は変えない）。「この役として保存」は、決まった部分（【あなたの役…】から役の決まりの文まで）はそのままで、後ろに書いた文を台帳の役の説明として保存する（決まった部分を直したときは今回だけ）。宛て先を替えると欄も替わり、直した分は残して知らせる（「元に戻す」で戻せる）。みんなに聞く・グループは席ごとの役の文のまま
- **朱書き**：至急・短く／じっくり／出典必須／反対意見も／断定しないで（至急とじっくりは片方だけ）。押したものは頼む文の末尾に「（朱書き・役より優先：急ぎ。3 行以内で。…）」の 1 行で入る。みんなに聞く・グループも同じ文
- **定型 6 つ**：送るものの下に「定型の組 ◀ 読みもの ▶」と 6 つのボタン。押すと頼む文の最後の行に入り、もう一度押すと外れる。数字 1〜6（文字欄の外）か Alt+1〜6（頼む文の中でも）でも同じ。組ははじめ、開いた入口で決まる（ページ・メモのセル＝読みもの、巣＝調べもの、六角スクショ＝スクショ、続けて聞く＝続き〔R5〕）。◀ ▶ で替えられる。「その他 ▾」は棚の定型の小さな一覧（押すと入る）
- 定型の穴 `{選んだ文}`・`{題名}` は、付けているものだけで埋まる（選んだ文は頭の 24 字の見本）。埋まらない定型は押せない。入れたあとで選んだ文・題名を外すと、その行も頼む文から外れる。頼む文の最後の行が今の組の定型の頭と同じなら下に候補が出て、→（行の終わりで）か Ctrl+Space で取り込める（日本語の変換中は出さない）。定型と使った回数は `ui-data\bots\presets.json`（左が書く。無ければ用意した 4 組〔R5 で「続き」を足した〕と棚を書く）。棚・蔵を整える画面は R4b
- **定型の棚**：巣の ⚙ に「**定型**」タブ（小窓の「その他 ▾」の足の「棚を整える…」でも開く。読む画面の小窓からは「巣の ⚙ で」と知らせるだけ）。組の札・**手元**（組ごとの 6。数字キーで入る）・**棚**（全部の組で一つ。最近使った順／当たりの多い順／ずれの多い順）・**蔵**（検索でだけ出る）。行ごとに最後に使った日・回数・当たり／ずれ／宛て先違いの数。行を押すと直す欄（文・**寿命**〔ずっと／今日だけ＝日付が変わったら／この調べものの間＝7 日使わなかったら、蔵へ〕・手元へ／棚へ／蔵へ・↑ ↓・消す〔二度押し〕）。押したらすぐ書く（「保存」は要らない）。棚の定型は 30 日使わないと蔵へ沈む（手元は灰色になるだけ。消すのは人）。棚から 3 回使うと「手元の一番使っていない『…』と入れ替えますか？」と一度だけ聞く（巣にも一度だけ知らせが出る）。言い回しの近い定型は **棚卸し** で並べる（これを残す＝ほかは蔵へ／別物＝もう並べない。声をかけるのは月に一度か、定型が 30 を超えたとき一度だけ）。組を替える軸はいまは入口だけ（サイト・子は「次の版で」）
- **送った依頼から拾う**：定型タブの下に、受け取り箱の依頼の頭（「依頼の最初の40字を一覧に出す」がオンのときだけ残る）と下書きの自分の文を、URL・題名・選んだ文の見本を穴 `{題名}`・`{選んだ文}` に置き換えた形で並べる（似た依頼はまとめて「似た依頼 n つ」）。直してから「定型にする」で棚へ。印の数は、今ある依頼（30 日・200 件）の印と、そこから片づいた依頼の印を `presets.json` に積んだ数の合計（付け外しできる間は積まない）
- **クリップボードの画像を候補に**：ページの右クリック・Ctrl+Shift+G・メモのセルから小窓を開いたとき、クリップボードに画像があれば、送るものに「**画像（いまクリップボードにあるもの）**」のカードが縮小図つきで出る（印は外した状態。付けなければどこにも送らない）。付けると、ブラウザが先に写しを取って `bot-shots\` に保存し、六角スクショと同じ **2 回貼り**（① 画像をコピーしてアプリを開く → ② 文）になる。頼む文には「画像を1枚、チャットに添えました（クリップボードの画像）」とだけ入る。画像は 1 体だけに送る（付けると宛て先の「みんな」は消える）。六角スクショ・渡し止めのサイト・右の巣から開いた小窓では出ない
- **画像に書き足す**：画像のカード（六角スクショ・クリップボードの画像）の「**書き足す →**」で、読む画面の上に書き足しの面が開く。丸・矢印・四角（箱）・番号・文字・黒塗り・ぼかしと「指さすだけ（● ここ）」。四角を引くたびに「箱ごとに問い」の行が増え、箱の角に番号が入る。指さすと周りの小さな切り抜きが並ぶ。一つ戻す（Ctrl+Z）・全部消す。渡す画像は「書き足した版」（既定）か「元の画像」（印なし・隠しなし）
  - 「小窓に戻る（画像を付けて）」で、① で貼る画像が書き足した版の PNG になり、依頼文の末尾に「①の箱：…」と（指さしたら）「ここは何？」が入る（画像を外す・元の画像にすると、入れた行は外れる。自分で直した行はそのまま）。カードに「この画像で送るもの：書き足した版（丸 1・箱 2・隠し 1…）」、頼む文の一文は「（…・書き足した版・印 n・箱 n・隠し n・指さし n）」。描いた画像はこの画面の中だけで作り、外へは ① で貼ったときだけ出る
- **隠す候補**：書き足しの面を開くと、画像の文字を **Windows の文字読み取り**（手元。画像は外に出ない）で読み、メール・電話番号・鍵らしき文字の行に**点線の枠**と「メールらしき文字。隠しますか？［黒塗りで隠す］［そのまま］」が出る。隠すかは自分で決める（黒塗りの道具と同じ印になり、一つ戻す・全部消すで枠が戻る。「元の画像」では隠せない）。決めずに小窓へ戻ってもよいが、カードと送る前の 1 行に「候補 1 未決」と出る。読み取りの無いビルド・日本語の読み取りデータが無いときは、枠を出さず「読み取りが使えません」とだけ出る
- **画像と文を一つの貼り付けで**（試し）：巣の ⚙「みんなに聞く」の「画像の貼り方」で選べる（既定は 2 回貼り）。選ぶと、画像を付けた依頼は「コピーしてアプリを開く」1 回で、渡す画像（書き足した版なら黒塗りを焼き込んだもの）と依頼の文が HTML に埋めた形で一緒にクリップボードへ入る（履歴・同期に入れない印つき）。Grok Bot アプリが受けるかはブラウザからは分からないので、送る前の 1 行に「画像入り 1 回（受けないと画像が落ちる）」と出し、「貼りましたか？」の札に「画像のフォルダを開く」「次から 2 回貼りに戻す」を出す。試して受けなければ、2 回貼りのまま使う
- **返し先「六角メモにも届く」**：小窓の返し先の 3 つ目。選ぶと、返事は受け取り箱に届き、確かめが通ったら（依頼と合う 1 通目の返事・灰色でない）ブラウザが六角メモ（相棒の設定の「六角メモへ」で選んだノート。今の「六角メモで開く」と同じ道）に 1 マス写す（箱にも残る・2 回は写さない・渡し止めのアドレスは伏せる・check と頼む文は写さない）。回答カードに「⬡ 六角メモにも届く」→「⬡ 六角メモに写しました」の札、写せなければカードの下に理由（「六角メモで開く」で手で送れる）。「アプリのチャットだけ」とは一緒に選べない。「前と同じで」でも戻る
- **そのまま送る（webhook）**：小窓の足の控えめなボタン。押すと送る前の 1 行の下が「↑ この内容で中継へ直接送ります（鍵は画面に出ない・貼る手は無い）［送る］［戻る］」の二段になり、送ると依頼の JSON（形と `replyTo` は今までどおり）を中継の受け口へ POST する。確かめたあとに中身が変わったら送らずに確かめ直し。押せないとき（鍵が無い・返し先がチャットだけ・画像あり）は足の上に小さくわけ。届かなければ（HTTP の失敗・15 秒で答えが無い）依頼は残し、同じ依頼（requestId は同じ・`attempt` 2）を「コピーしてアプリを開く」に切り替えられる（小窓・受け取り箱の伝票から）。webhook で送った依頼の追跡票は「貼った？」を飛ばし、「貼りましたか？」の札も出さない
- **みんなに聞くを webhook で一括**：「そのまま送る」は、みんなに聞く（1体ずつ）とグループでも押せる。案内を出さずに、席ごとに依頼を作って中継へ 1 つずつ送る（代表にまとめては 1 つの依頼）。届かない席があればそこで止め、その席は同じ依頼をコピーに切り替えられ、まだの席は下書き（未送信）に残る
- **送り方の鍵の置き場**：巣の ⚙ の「送り方」タブで、中継の受け口の URL（https だけ）と鍵（Bearer）を入れて「しまう」。C++ が Windows の暗号化（DPAPI）で `bot-hook.bin` にしまい、欄はすぐ空にする。画面・記録・依頼文・`ui-data` には出さず、UI に返るのは「ある／ない」だけ（`getApiKey` と違い値は返さない）。「鍵を消す」で消せる。中継の受け口は各自が用意する（このリポジトリには入っていない。無ければ送っても届かない）
- **前と同じで**：定型の組の行の「その他 ▾」の前。押すと、前回コピーした依頼の選び方（定型の組と定型・宛て先・返し先・朱書き・URL／題名／選んだ文の印）に戻す。本文は外したまま。書きかけの頼む文には触らない（空のときだけ前回の定型を入れる）。ページで **Ctrl+Shift+G を素早く 2 回**（0.7 秒のうち）押しても同じ。選び方は `ui-data\bots\last-request.json`（左が、コピーしてアプリを開けたときだけ書く。頼む文・選んだ文・URL の中身は入れない）。送る前の 1 行の色は、この前回の選び方と比べる（宛て先・付けたものの種類・返し先。字数がちがうだけでは色を付けない）ので、戻したあとは色が付かない
- **続きとして**：宛て先の上の選び口から、最近の返事（確かめが通ったもの 5 件）を選ぶと、頼む文の頭に「#0001 の続き：（返事の頭の 1 行）」が入り、宛て先がその依頼の席に替わる。下に返事の要点の行が印つきで並び（左が記録の全文から作る）、**印を付けた行だけ**が、添えた情報の枠に「前の返事 #0001（データ）：」として入る（頼む文や依頼の JSON には入れない）。定型の穴 `{前の返事の要点}` は印があるときだけ「#0001 の要点」で埋まる。回答カードの「続けて聞く」は、その返事を選んだ状態・入口「続けて聞く」（定型の組「続き」。R4a で書いた `presets.json` には無いので「調べもの」）で開く。「前と同じで」は続きの選びに触らない（`last-request.json` に続きの元は入れない）
- **糸**：続きとして頼んだ依頼は `pending.json` に続きの元（`parentRequestId`）を覚え、受け取り箱の一覧で「糸：（最初の依頼の頭）#0001 → #0004」の点線の枠に、最初の問いから順に束なる（頭が無ければ「#0001 から」）。回答カードにも糸の 1 行。みんなに聞くの 1体ずつ・グループ・まとめ役は糸にしない
- **送ったあと**：受け取り箱のいちばん上に **伝票レール**（横に送る。待っている依頼は経過と「受領：まだ／あり」〔相手の最初の途中経過が受領の印〕、途中経過 n/10、15 分で橙、**知らせの期限**〔巣の ⚙ の「みんなに聞く」→「送ったあと」。既定 3 時間〕を過ぎたら赤、届いてまだ読んでいない返事は緑。「閉じる」はレールから外すだけ）と、押した伝票の **追跡票**（受け付けた → 貼った？ → 相手が受け取った → 作業中 → 届いた）。巣の席は、頼んでいる席が点線（期限を過ぎたら赤の点線と赤い札）、返事が届いた席は光り、押すとその返事へ飛んで光が消える。ブラウザを閉じている間に届いた返事は、次に開いたとき **不在票**（「昨夜 2 通届きました」）が 1 枚出る
- **貼りましたか？**：依頼をコピーする前に、クリップボードの前の中身を預かる（文字・HTML・画像〔長い辺 1600px の写し〕。メモリの中だけ・画面に出さない・閉じれば消える）。Grok Bot アプリから戻って 30 秒（巣の ⚙ で 3〜600 秒）たっても依頼がクリップボードに残っていれば、受け取り箱に札が 1 枚だけ出る：**貼った**（預かりに戻す）・**もう一度開く**・**消す**（依頼を消して預かりに戻し、待つのもやめる）。相手の途中経過か返事が先に届けば聞かずに戻す。クリップボードがもう別の中身なら何も戻さない。ブラウザは貼ったかどうかを知れないので、聞くだけ。上の箱は **未送信**（小窓を途中で閉じた依頼と、コピーできなかった依頼。「送り方を選び直す…」で小窓を開き直す・「下書きに戻す」）
- **中継の見張り**：伝票の下に「返事を取りに行く常駐：動いています（最後 23:41）」と **いま取りに行く**・**試し便を送る**（決まった一文だけの依頼〔`type: "ping"`〕をコピーしてアプリを開く。届いたら往復の時間と照合 ✓／✗ だけを出す。鍵や中継の場所は出さない）
- **まず 1 枚**：未送信の箱と一覧のあいだに、前に「読んだ」にしたあとに届いた、まだ読んでいない返事の表（番号・宛て先・頼んだ一言〔巣の ⚙ で最初の 40 字をオンのときだけ〕・返事の一言・**続けて聞く**／**メモに置く**〔右のメモ〕／**片づける**〔読んだにするだけ。箱には残る〕）。合わない返事（灰色・預かり）は 1 行にまとめる。不在票の「まず 1 枚へ」でここへ飛び、不在票の数は表の数とそろえる。試し便は入れない
- **回答カード v2**：先頭に **一行の答え・次の一手・どのくらい確か**（返事にその見出しがあれば。返事の決まりで、はじめに書いてもらうよう頼んでいる）。足は「⬡ 六角メモで開く／タブに残す／**もう一度 ▾**（同じ子に続けて聞く・**別の子へ渡す**〔巣の次の子へ、要点の行を添えた情報に〕・**言い換えてもう一回**〔一覧では #0010-2〕・**頼み方を直す**〔役の文・定型・残っていれば頭の 40 字に分けて開く〕）／**当たり・ずれ・宛て先違い**」（もう一度押すと外れる。使った定型と役に溜まり、定型の数は R4b の棚に出る）。一覧の下の隅に「今月 n 通・約 n 万字（量の目安。料金は出ません）」
- **受け取り箱**は、データ置き場の下のボットの欄。見出しは「受け取り箱」。輪の下の1行からも、ボットのセルのカードの「やり取りを見る」からも開ける。確かめの済んだ返事は回答カードになる（「ボットの返事を受け取る（第2段）」）
- 六角形スクショは巣のボタンではない。盤面やページの「六角形スクショ」の節から撮る
- 相棒とは別物。巣の顔はボットのセルと同じ石板の色。相棒の顔・切り替え・会話の入力欄はそのまま
- 並びは台帳の `dock`（`ui-data\bots\index.json`）。右サイドバーは左から台帳の写しをもらい、変えたいときは左に頼む（`ui/src/panels/bot-dock.ts`）
- グループの割り当ては `ui-data\bots\groups.json`（席・各ボットの役とは別。`ui/src/bot-teams.ts`）。登録・頼み方・まとめ役は、下の「Grok Bot のグループ」
- ブラウザから宛先へ直接送る道は、まだ無い。送り方は、コピーしてアプリに貼るのまま

### Grok Bot のグループ

5つの組（まとめる・調べる、考える、確かめる、動かす、伝える・組み立てる）に、役ごとのボットとまとめ役を登録して頼めます。巣の6つの席の並びや、各ボットの「席の役」とは別です。ここで選んでも、席と席の役は変わりません。1体を、いくつかの役やいくつかのグループに選んでもかまいません。自分で作る役は、グループには入りません。グループは5つのままです。

**登録する。** 右サイドバーを開き、下の巣の ⚙ →「役」→ 上の **グループ**。組ごとに、役のボット（「選ばない」もある）と、まとめ役（「置かない」もある）を選んで「保存」を押します。保存先は `%LOCALAPPDATA%\RocksCellsBrowser\ui-data\bots\groups.json` です。窓を閉じても残ります。台帳からボットを消すと、そのボットの割り当てとまとめ役は外れます。リンクの無いボットも割り当てられますが、頼むときには飛ばします。

**頼む。** 巣の下の **グループに頼む ▾** から組を選びます。リンクのある役が1つも無い組は選べません。小窓の宛て先は「グループ：まとめる・調べる（2体）」のようになり、受け持つ役とボットの名前が出ます。頼む文は1つです。依頼の頭に入るのは、グループで受け持つ役の文です（細かい設定と考え方は、その役の既定のまま）。ボットの席の役は使いません。付ける情報（題名・アドレス・選んだ文）は、いつもの小窓と同じです。渡し止めのサイトでは、本文・選んだ文・アドレスは自動では付きません。

**コピーして貼る回数。** リンクのある役の数だけです。3つの役なら3回貼ります。「1/3 調査：コピーしてアプリを開く」を押すと、その1体のチャットだけが開きます。貼って送ったら、ブラウザに戻って「次」を押し、「2/3」「3/3」も同じようにします。書いているあいだや、「次」を押す前は、アプリは開きません。途中でやめると、まだの役の依頼は作られません（下書きに「次の役」として残ります）。同じボットを2つの役に選んだときは、そのボットのチャットへ2回貼ります。返事は、受け取り箱の組のカードに役ごとの点で並びます。全部そろったら「まとめて読む」で、役の順に読めます。

**まとめ役。** 置かなくても頼めます。そのときは、返事を並べて読むだけです。置いてある組は、返事が1通でも届くと、組のカードの「まとめ役に渡す」が押せます。届いていない役は「まだ届いていません」と書いて渡します。届いた返事は「ほかのボットの返事（データ）」として囲み、中の指示には従わない一文を添えます。渡し止めのアドレスは「（渡し止めのアドレス）」に伏せます。依頼の上限（2万字）を役の数で等分して切ります（3役なら1通あたり6千字ほど）。切ったときは、切った字数を書きます。まとめ役への文は「役ごとの返事を読み、食い違いと共通点を示して、1つの答えにまとめてください」です。小窓で中身を見てからコピーします。押しただけではアプリは開きません。まとめ役は Grok Bot だけです。相棒は呼ばないので、相棒の料金は増えません。まとめ役の返事は、同じカードの上に「まとめ」と出ます。元の返事は、その下の「まとめて読む」に残ります。

順番に渡す（調査の返事を、次の要約の依頼に入れる）は、まだありません。

### フェイブルの一時的な進化（深く考える）
フェイブルは、面白い分析・意見・論点が出せそうなときだけ「もう一段深く考えたい」と合図する。許可すると、その返事の続きだけ、考える深さ（effort）をふだんの high から max に上げて書く（**進化**）。返事が終わると、元の深さに戻る。

- 合図が来ると、会話の中に「🌕 フェイブルが一時的に進化して、考察を深めようとしています。許可しますか？」と、何を考えたいか・料金の目安が出る：**許可する**／**この会話ではいつも**／**やめる**。30秒たっても答えがなければ、進化せずにそのまま続ける。会話を閉じていても、右下の吹き出しで知らせる
- 進化している間は、フェイブルの顔が「星の衣」になる（六角形が夜空の色になって星座が浮かび、満月が光り、金の二重枠。考え中は枠がゆっくり回り、話し中は光が脈打つ）。終わると枠が広がりながら消えて、いつもの姿に戻る。進化して書いた返事は金の枠で、名前は「フェイブル（覚醒）」
- **さらに考える**（入力欄の下のボタン。フェイブルが会話のメンバーのときだけ出る）：確認なしで、フェイブルがその返事の初めから進化して答える。入力欄の文に答える（空なら、ここまでの話を深める）。説明はボタンにマウスを乗せると出る
- 進化の枠は、フェイブルの合図とボタンで **1日の回数を分け合う**（標準3回）。残りは翌日に持ち越さず、0時に戻る。残りの回数は **月の満ち欠け** で出る（満月＝まだ全部、新月＝もう無い。ボタン・⚙・許可を聞く欄）
- ⚙ の「フェイブルの進化」：**毎回聞く**（標準）／**この会話ではいつも許可**（会話ごとに最初の1回だけ聞く）／**進化しない**、**1日に進化できる回数**、**フェイブルの合図用に1回残す**（ボタンでは最後の1回を使わない。使われなければ、その日のうちに消える）。今日の残りも出る
- 進化した返事がうまくいかなかった（通信の失敗など）ときは、使った枠を返す（自分で止めたときは返さない）
- 料金の目安：進化した返事は1回 約 $0.20〜$1.00（Claude Fable 5.1 は入力 $10・出力 $50 / 100万トークン。考える量しだい）。かかった料金は返事の下に出る
- しくみ：考える深さを変えるのは、会話の途中に足す「深さだけの」指示（Anthropic のベータ `mid-conversation-output-config-2026-07-01`）。会話の履歴は後ろに足すだけなので、前の部分の読み直しの割引も切れない。Anthropic に送るものは、ふだんの会話と同じ（進化のために増えるものはない）
- 「視覚効果を減らす」設定（Windows）のときは、動きを止める

### フェイブルレター
フェイブルが一時的に進化して深く考えた返事で、あとで読み返す価値のある考察が得られたとき、レターにして提案する。残すかどうかは使う人が決める。

レターは3段で読む：
1. **3行の要点**（何について考えたか・気づいたこと・次に試せることか残る問い）
2. **手紙**（400字ほど・フェイブルの語り口）
3. **元の会話**（見たいときだけ開く。レターを残したときの、使う人の発言とフェイブルの返事）

（3行の要点と元の会話は、この形にしてから残したレターだけ。前に残したレターは、手紙と「元の会話を開く」（その会話を開き直す）になる。前の形で話し始めた会話では、フェイブルは前の形（題名と手紙）で提案する＝会話の途中で道具の文を変えない）

- 提案は返事の下に「✉ フェイブルからのレターの提案」として出る：**レターにする**／**やめておく**。進化していない返事では提案しない（1つの返事で1回まで。⚙ の「フェイブルの進化」を「進化しない」にすると、提案もしない）
- 残したレターは、会話の「履歴」→「✉ フェイブルレター」の一覧に並ぶ（新しい順。`ui-data\letters.json`、500通まで。いっぱいになったら古いものを消してから）
  - **盤面に置く**：表示中のタブの近くに、「レター・フェイブル」の印つきのメモのセルとして置く（題名が見出し、最後に書いたキャラと日付）
  - **コピー**：メモのセル1つとしてコピーする（盤面の空いたセルで Ctrl+V すると、印つきのメモのセルになる）
  - **教材にする**：押したときだけ、手紙から単語帳のカードの案（言葉・問い）を作る。印を付けたものだけ単語帳に入れる（AI を使う。料金はカードを作るときと同じくらい）
  - **🌙 月の窓に出す**：「公開してよい」の印（使う人だけが付ける）。付けたレターが、下の「月の窓」に映る。もう一度押すと外れる
  - **消す**（2回押す）
- 提案するかどうかの判定は、差し替えられるようにしてある（今はフェイブル自身の判断）
- 練習モードでは、フェイブルがメンバーのときに「さらに考える」で「レターにして」と頼むと、練習用のレターが提案される

### 月の窓
右サイドバーのいちばん上、「パネル」の見出しのすぐ下の、紫の夜空の区画です。出すものは札で切り替えます（2つ以上あるときだけ札が出ます）。

- **✉ レター**：「公開してよい」の印を付けたフェイブルレター
- **⬡ Grok Visions**：Grok Bot が残した Vision（巣の設定で出せるとき）
- **⟳ めぐる**：単語帳とリマインダー。右上の ⚙ で入れたときだけ（はじめは切ってあります）

レターも Vision も無く、めぐる表示も切っているときは、区画ごと出ません。めぐる表示を入れていれば、レターが無くても出ます。

区画の右上は、‹ ›（前後）、⏸（入れ替えを止める。止めたことは覚えておく）、⚙（めぐる表示とひとこと）、▾（たたむ。題名だけになる）です。

#### レター
「公開してよい」の印を付けたフェイブルレターを、1通ずつ映します。

- 8秒ごとに次のレターへ入れ替わります（区画の高さは、印を付けたレターのいちばん長いものに合わせるので、入れ替わっても下のパネルは動きません。高すぎるときは区画の中で動かします）
- マウスを乗せている間・キーボードで中のボタンを選んでいる間・手紙や会話を開いている間は、入れ替わりません。Windows の「視覚効果を減らす」設定のときは、入れ替わるときのふわっと出る動きだけを止めます
- **手紙を読む** で2段目（手紙）、続けて **元の会話を見る** で3段目（元の会話）。**一覧で見る** で相棒の「履歴」→「✉ フェイブルレター」のそのレターへ
- 月の窓は、このブラウザの中だけです（どこにも送りません）。外に公開する SNS は将来の案

#### めぐる表示
⚙ の「めぐる表示を使う」に印を付けると、札に「⟳ めぐる」が出ます。選んだものを、決めた間で1つずつ映します。レターと Grok Visions の8秒は変わりません。めぐる表示そのものは、AI を使いません。はじめは切ってあります。

- **映すもの**（⚙ の中）：単語帳、リマインダー。両方に印があるときは、交互に映します
- **単語帳から**（⚙ の中）：全部／⟳ の印だけ（単語帳の行の ⟳ で付けたカード）／今日の復習と苦手だけ。「⟳ の印だけ」で印のカードが 1 枚も無いときは、札に「⟳ の印を付けたカードがありません」と「全部を映す」が出ます。「新しく入れたカードに ⟳」に印を付けると、入れる小窓の ⟳ がはじめから付きます
- **入れ替える間**：30秒・1分・3分・5分・10分。はじめは1分
- **単語帳**：表（と、カードに画像があれば表の下に画像）を出します。「答えを見る」で裏が出ます。並びは、今日の復習 → 苦手 → ほか。答えを開いている間は、次のカードに替わりません。「単語帳で開く」で、右サイドバーの「単語帳」パネルのそのカードへ移ります。セルを登録したカードには「セルへ：題名」（先頭のセル）
  - 答えを開いたあと、今日の復習のカードには「できた」「もう一度」、ほかのカードには「もう一度」が出ます（押すと単語帳の評価になり、そのカードは今日はもう映しません）
  - **🔔 あとで**：1 時間後にもう一度映します（それまでは出しません）
  - **…**：「今日はもう出さない」（明日にはまた出ます）、「⟳ の印だけ」のときは「⟳ の印を外す」
- **このページ n 枚**：左で表示しているページから作ったカード（カードの出典が同じページ）があると、上に札が出ます。押すと、そのカードだけを映します（「戻す」か、タブやページを替えると、いつもの並びに戻ります）
- **月の形**：単語帳を映しているときは、今日の復習の残りで月が欠けます（全部済むと満月）
- **リマインダー**：文と「あと n 分」。まだ時間になっていないものを、近い順に映します（「次に開いたとき」「次に起動したとき」のものは映しません）。時間になったものは、次に替わるときに外れます。右の「リマインダー」パネルで取り消すと、めぐる表示からも消えます。「リマインダーを見る」で、そのパネルへ移ります。「そのセルへ」（指す先があるとき）・「10 分延ばす」・「済み」。タブの題名は出しません
- **次は 14:30 …の帯**（⚙ の中。はじめは切ってあります）：次のリマインダーを、月の窓の頭の下に出します。5 分前から金色になります。押すと「リマインダー」パネルへ
- 映すものが1つも無いときは、この札に「映すものがありません」と出ます
- マウスを乗せている間・キーボードで中を選んでいる間・⏸・たたんでいる間・⚙ を開いている間・右サイドバーを閉じている間・ほかの窓に隠れている間は、入れ替わりません
- 答えを閉じている間は、カードが替わっても区画の高さは変わりません（下のパネルが動きません）

#### AI のひとこと
同じ ⚙ の「AI のひとこと」です。めぐる表示とは別に入れます。はじめは切ってあります。印を付けただけでは動きません。「入れる前の確認」で、渡すもの・渡さないもの・料金の目安を見て、「入れる」を押すまで付きません。組や種類を変えて渡すものが増えるとき（高い組にする、種類を足す、単語帳を「両方」にする、答えの前から答えの後にして裏を渡すようにする）は、確認がもう一度出ます。

付ける場所は、単語帳だけ選べます。標準は「答えの後」です。

- **答えの前**：表の下、答えを開く前に出ます。答え・訳・言い換え・綴りは書きません。使う場面や最初の音で、みんなで考えます。AI には表だけを渡します（裏は渡しません）
- **答えの後（今の場所）**：「答えを見る」を押したあと、裏の下に出ます。AI には表と裏を渡します
- **両方**：1枚で2回呼びます。答えの前が付いてから、決めた間があいて、もう一度10秒映してから、答えのあとが付きます。料金・1日の回数・ひとことの間も、2回ぶんです。確認の料金の目安も、この場所に合わせて変わります
- リマインダーに場所はありません。カードの文の下に、1回だけ出ます

**渡すもの**は、それだけです。単語帳は表（答えの後は裏も）と、言葉か問いか。リマインダーは文と、あと何分か。ページのアドレス、題名、ページの中の文、リマインダーに付いたタブの題名は渡しません。

**組**（選ぶ欄に、1回の料金が出ます）：

| 組 | 画面に出る名前 | 1回 | 1日10回で1か月 |
|---|---|---|---|
| ハイク組（標準） | ツクシ・ホタル・モミジ | 約 $0.0002 | 約 $0.05 |
| ソネット三人組 | ルカ・ジン・モモ（⚙ で名前を変えられます） | 約 $0.0030 | 約 $1 |

どちらも、1回の呼び出しで3人の1行ずつです（3回は呼びません）。表示は目安で、実際の請求とは一致しません。練習モードのときは API を呼ばず、「（練習）」の文だけ出します。料金は増えません。

**止まるとき**（この全部を満たしたときだけ、回数が増えます）：

- めぐる表示が、そのものを見えるように映している（画面が見えている、右サイドバーが開いている、月の窓をたたんでいない、⏸ にしていない、⚙ を閉じている）
- 映ってから10秒たった（マウスを乗せているあいだも数えます。読むのを止めません。答えを開いていても数えます）
- 前のひとことから、決めた間があいた（標準10分。5〜60分）
- 今日の回数が、1日の上限に達していない（標準10回。1〜50回。0時に戻ります）。⚙ に「今日 n/上限 回」と出ます
- 同じ場所には、同じ日に1回だけ。覚えたひとことは `ui-data\rotate\comments.json`（200件まで。古いものから消します）。同じカードがまた映っても、呼び直しません
- 月の上限の8割に近づいたら、ひとことだけ先に止まります。めぐる表示そのものは回り続けます。⚙ に「上限に近いので止めています」と出ます
- API キーが無いときは、ひとことは出ません。今日の回数は増えません。⚙ に「API キーが無いので、呼んでいません」と出ます
- 呼んで失敗したときは、ひとことは出さず、⚙ にわけが1行出ます。その回は、今日の回数に入ります

ひとことの下の **会話に残す** を押したときだけ、右サイドバーの下の方にある相棒の会話のいちばん下に、「月の窓のひとこと」の1行が残ります。このボタンは AI を呼びません。押すまでは、会話は変わりません。

### メモの区画（右サイドバー）
右サイドバーの下のパネルのいちばん上にある「メモ」。上は蜂の巣、まん中が書く欄、下が書いたコメントの一覧。

- 書いたコメントは、1つずつ、今のタブのシート（はじめは「右のメモ」）のメモのセルになる（真ん中から外へ、空いている所に置く）。右のシートは左のシートの一覧にも出るので、左で開けば、ふだんの盤面と同じように動かしたり、タグを付けたり、書き直したりできる
- **シートのタブ**（見出しのすぐ下・6つまで）：押すとそのシートに切り替わる。**＋** で新しいシートを足す（名前は「右のメモ 2」などから変えられる）。**×** でタブから外す（シートは消えない。書いたものがあるシートは、もう一度押して確かめる。何も書いていない、右で作ったシートだけは片づける。最後の1つは外せない）
- **セットに保存**：今のタブのシート（6つまで）に名前を付けて「シートのセット」として保存する。保存したシートはタブから外れて「セット ▾」の一覧に入り、タブには新しい空のシートが1つ入る（左の「セット」〈セルの並びのセット〉とは別のもの）
- **セット ▾**：シートのセットの一覧。**開く** でそのシートがタブに戻り、セットは一覧から外れる。今のタブのシートに書いたものがあれば、「保存して開く／保存せずに開く／やめる」を聞く（どちらでもシートは消えない）。**消す**（2回押す）はセットだけを消す
- 右で作ったシートが、何も書かないままタブから外れた（セットにも入っていない）ときは、左のシートの一覧からも片づける（本当に空のときだけ）
- タブとセットの保存先は `ui-data\right-sheets.json`
- 蜂の巣は、空いた所のドラッグ・ホイール（Shift＋ホイールで左右）・矢印キーで上下左右に動かせる。◎ で真ん中（印を付けたセル）に戻る
- **空いたセルをダブルクリック**（または右クリック →「ここにメモを書く」）すると、その場所にメモを書ける。書く欄がその場所のすぐ下に出る（Ctrl+Enter か「ここに置く」で置く、Esc か「やめる」でやめる）
- **メモのセルはドラッグで動かせる**。ほかのセルの上に落とすと場所を入れ替え、入口に落とすとそのシートへ移る（左の盤面と同じ決まり。入口の上では、落とす先が濃い色になる）。蜂の巣の端の近くまで引くと、蜂の巣も少しずつ動く。蜂の巣の外で離すと、動かさない。「右のメモ」に移したタブは、左の盤面で動かす
- 下の一覧は新しい順で、上下に動く。それぞれに返信を付けられる（今あるコメントのスレッドと同じ。相棒にも返信してもらえる）
- コメントには **タグ** を付けられる。一覧には付いたタグが出る。付ける・外すのは、一覧のすぐ下の **選んだコメントのタグ**（コメントか蜂の巣のセルを1回押すと、そのコメントの「＋タグ」と右の **タグのボタン** が出る。「タグのボタン」の節）。タグごとに見るには、すぐ下の「タグごとの一覧」
- セルとコメントの行き来：セルを**ダブルクリック**すると下のコメントへ、コメントを**ダブルクリック**（または「セルへ ↑」）すると上のセルへ。**右クリック**のメニューにも「コメントへ移る／セルへ移る」がある。1回押すだけなら、両方に印が付く
- 右クリックのメニュー：**コピー**（メモのセル1つとして。左の盤面の空いたセルで Ctrl+V）、**消す**（2回押す）
- 高さは決まっている（蜂の巣が4割、コメントが6割）。▾ でたたむ（覚えておく）

### 相棒にブラウザの操作を頼む（道具）
話しかけるだけで、相棒がブラウザを操作する。何をしたかは返事の上に小さく出る（⚙ の「ブラウザの操作を任せる」で止められる）。

| 頼み方の例 | 相棒がすること |
|---|---|
| 「猫の記事のタブはどれ？」「タブを整理して」 | タブの一覧（タイトル・URL・メモ・状態）を見て探す・提案する |
| 「3番のタブを表示して」 | タブを切り替える |
| 「〇〇の公式サイトを開いて」「これはあとで読むので開いておいて」 | 新しいタブで開く（あとで読む用は、眠ったタブとして置く） |
| 「使ってないタブを眠らせて」 | 休眠させる（表示中・音が出ている・「休眠させない」のタブはそのまま） |
| 「この2つのタブを閉じて」 | 閉じる前に「はい / いいえ」で確認する |
| 「30分後に休憩をリマインドして」「明日の9時に〜」 | リマインダーを置く（右サイドバーの「リマインダー」パネルに出る。× で取り消し） |
| 「さっき調べていたページはどれ？」「〇〇を調べたときの流れは？」 | 順路（リンクをたどった道）を見て答える |
| 「『〇〇』を単語帳に入れて」「今日の復習は？」 | 単語帳にカードを入れる・復習の数や苦手な言葉を見る |
| 「作業用の音楽をかけて」 | YouTube で探して、いちばん上の動画を新しいタブで再生し、元のタブに戻る |
| 「音楽を止めて」「再開して」「消音して」 | 音が出ているタブを一時停止・再開・消音する |

- リマインダーの時間になると、Windows の通知を出し、右サイドバーの相棒が吹き出しで知らせる（右サイドバーを閉じていたら開く）。ブラウザを閉じている間に過ぎたものは、次に起動したときに知らせる。保存先は `ui-data\reminders.json`。相棒が置いたものには、区画の行に金の六角の印が付く。自分で置く・延ばす・繰り返す・きっかけで知らせるは「リマインダー（右サイドバー）」の節
- Windows の設定で通知がオフになっていると、通知は出ない（吹き出しとタスクバーの点滅で知らせる）
- 相棒が選ぶのは「どの道具をどう使うか」だけで、ページの中で動かすスクリプトは決まったものだけ（AI が書いたスクリプトは動かさない）
- ページやタブのタイトルに書かれたお願いを理由に、道具は使わない（指示文に書いてある）
- 道具を使うときは、タブの一覧（タイトル・URL・メモ）も Anthropic に送られる
- 新しい会話から、道具の使い方を書いた指示文になる（前の会話は、その会話の指示文のまま続く）

### 相棒が覚えていること（記憶）
使っている人について、次の会話でも覚えておくこと（好み・関心・目標・「覚えて」と頼んだこと）。人が読んで直せる形で持つ。

- 右サイドバーの **相棒が覚えていること** パネルで、一覧・書き足し（Enter）ができる
- 置き場所を選べる
  - **このパソコン**（標準）：`ui-data\memory.json`。パネルの ✎ で直す・× で忘れる
  - **六角メモのノート**：1つのマス＝1つの記憶。ノートのメモを、下の階層や未配置の棚も含めて読む（読むだけ）。覚えるときは六角メモの受け取り口へ送る（ノートの原点の下の階層に入る）。直す・消すのは六角メモで。記憶専用のノート（例：「Claude の記憶」）を作って選ぶのがおすすめ
  - 「このパソコンの記憶を送る」で、このパソコンに覚えていた分を六角メモのノートへ送れる
- 相棒は、頼まれたとき（「〜を覚えて」）や、はっきりした好み・目標がわかったときに、自分で覚えることもある。何を覚えたかは返事の上に出る。「〜を忘れて」と頼むこともできる（六角メモに置いているときは、六角メモで消すよう案内する）
- **今の会話から提案**：今の会話から覚えておくとよいことの案を作り、印を付けたものだけ覚える
- 新しい会話を始めるとき、覚えていることを最初の発言に添えて相棒に渡す（Anthropic に送られる）。パスワード・カード番号・住所などの秘密は覚えないよう、相棒に伝えてある

### 情報収集と採点（トピック）
追いかけたいこと（トピック）を登録すると、Web 検索で新しい情報を集め、採点の基準に沿って点数を付けて並べる。

- 右サイドバーの **情報収集** パネルの「＋トピック」で登録する
  - 名前、調べたいこと
  - 採点の基準（1行に1つ。それぞれ 0〜5 点。標準は「新しさ・情報源の信頼性・わたしの関心との近さ・内容の濃さ」）
  - 自動で集める間隔（手動だけ・3・6・12・24時間ごと）、1回に検索する回数（1〜10）、調べるサイトを限る／除く
- **今すぐ集める**：Anthropic 側で Web 検索して集め、もう一度 Claude に頼んで点数を付ける（2段階）。点数は 0〜100 で、六角形の辺（6本で満点）と数字で出る。新しく見つかったものには「新着」が付く
- 検索で実際に見つかったページの URL だけを残す（AI が作った URL は出さない）。ページに書かれた指示には従わないよう、AI に伝えてある
- 項目のタイトルを押すと新しいタブで開く。「＋」で後で読む用に眠ったタブとして置く。「×」で要らない（次からも出さない）
- **島に並べる**：点数の高いもの（6件まで）を、眠ったタブとしてトピックと同じ名前の島に並べる。点数に合わせて ♥（80点以上 ♥3、65点以上 ♥2、50点以上 ♥1）。もう開いているページは、重ねて開かずに島に入れる
- 自動で集めるのは、ブラウザと右サイドバーを開いている間だけ。1日の回数に上限がある（標準6回）。新しいものが見つかると、相棒が吹き出しで知らせる
- 相棒に「〇〇をトピックにして」「〇〇の情報を集めて」「トピックの一覧を見せて」と頼むこともできる
- 料金の目安：検索1回 $0.01（1,000回で $10）と、読んだ分のトークン。1回集めるとだいたい $0.05〜0.3（モデルと検索回数による）。最後に集めたときの料金をパネルに出す
- 使う人の関心として、相棒が覚えていることも採点に使う（Anthropic に送られる）。保存先は `ui-data\topics.json` と `ui-data\topics\`

### 相棒の Web 検索
- ⚙ の「Web 検索を使う」が入っていると、相棒が新しい情報の要る質問（「最新の〜は？」など）で Web 検索する（1回の返事で3回まで）
- 何を検索したかは返事の上に、引用元は返事の下の「参考」に出る（押すと新しいタブで開く）。検索の料金も返事ごとの料金に入る
- フェイブルが Web のページを取得して読んだときも、読んだページが返事の上と「参考」に出る

### AI の返事を残す
返事の下のボタンで、返事を別の場所に残せる。

- **タブに残す**：そのページのタブのメモになる。拡大表示のカードに「メモ n」と新しい順の3件が出て、× で消せる。セルの左上に ✎ が付く。メモはタブと一緒に保存される
- **六角メモへ**：六角メモのノートへ送る（送り先は ⚙ の「六角メモの送り先」で、メモアプリ › ノートを選ぶ）。
  六角メモの「コピーして送る」と同じ受け取り口（データフォルダの `inbox\`）に置いて合図するだけで、取り込むのは六角メモ自身（六角メモのファイルは直接書き換えない）。
  ノートの原点の下の階層の空いたマスに、本文・タグ（Claude・要約など）・ページのリンク付きで置かれる。六角メモが止まっていても、画面を出さずに取り込まれる
- **データ置き場へ**：右サイドバーの「データ置き場」（メモの区画のすぐ下）に入れる（下の「データ置き場」を参照）
- **コピー**

### データ置き場（右サイドバーのメモの区画の下）
AI の相棒との会話と、相棒が作ったものを残しておく区画。右サイドバーの下のパネルの欄の中で、メモの区画のすぐ下にある（欄といっしょに動くので、相棒の会話の入力欄を下へ押し出さない）。▾ でたたむと見出しだけになる（たたんだことは覚えておく）。区画の高さには上限があり、項目が多いときは区画の中で動かす。見えていないところで入れたときは、右のお知らせでも知らせる。

- 入れるもの（AI の相棒のものだけ）
  - **会話**：見出しの **＋会話**、または相棒の会話の見出しの **📥** で、今の会話を残す。会話は**画面の見た目のまま画像**にする（スクロールで隠れた部分も含めて全部。長い会話は何枚かの画像に分ける）。同じ項目に、会話の**文字のデータ**（読みやすい文字と、発言ごとの記録の JSON）も入る。相棒が返事を書いている途中は残せない
  - **返事**：相棒の返事の下の **データ置き場へ**（押すと「置き場に入れました ✓」になる）
  - **考察のメモ**：相棒が盤面に残したメモのセル（拡大表示のカードの **データ置き場へ**。フェイブルレターは除く）
  - **情報収集**：情報収集のトピックの **データ置き場へ**（今出ている結果を、点数・URL・要約・理由つきで）
  - **単語帳の案**：「AI でページから」作ったカードの案の **データ置き場へ**（印を付けたもの。単語帳に入れるかどうかとは別）
  - タブの中の Web の AI（ChatGPT などのページ）の会話・そこから落としたファイル・フェイブルレターは入れない
- 項目を押すと開く：会話の画像の1枚目（押すと全部の画像を大きく見る。Esc か × で閉じる）、文字（**全部見る** / **たたむ**）、**タグ**（タグのボタン・色は、ほかのタグの欄と同じ。右サイドバーのタグのボタンを使う）。上のタグの印で、そのタグの項目だけに絞り込める
- **六角メモへ**：相棒の ⚙ の「六角メモの送り先」に、文字（題名と本文）をタグ（項目のタグ・データ置き場・種類）つきで送る。返事の「六角メモへ」と同じ受け取り口を使い、送り先は使う人が選んだところだけ（決め打ちの送り先は無い）。画像は送らない
- **メモのセルとしてコピー**：六角メモと同じクリップボードの形でコピーする（六角メモや盤面に貼れる）。**文字をコピー** は文字だけ
- **消す**：確認の欄で「消す」を押すと、画像と文字のデータも消える（元に戻せない）。数や大きさの上限は無く、見出しに使っている大きさの目安（約 n MB）を出す。📂 で保存場所のフォルダを開く
- しくみ：会話を、右サイドバーの画面の外（下）に見た目のまま全部の高さで描き直し、C++ が WebView2 の DevTools の `Page.captureScreenshot`（`clip` と `captureBeyondViewport`）で撮って PNG のファイルにする。1枚の高さは約 8000 ピクセルまで（Chromium の上限より小さく）。全部を撮れなかったときは、見えている部分だけを撮る（それも無理なら文字だけ）。その旨は項目に出る

### 保存と復元
- タブの配置・番号・タイトル・アイコン・「休眠させない」の設定・メモ・♥・読んだ量・タグ・島・順路のどこにいるか・シート・見た目（画像・コメント・見え方）と、シートの台帳・見ていたシートは `%LOCALAPPDATA%\RocksCellsBrowser\session.json` に自動で保存される（閉じるときにも保存してから閉じる）
- データ置き場は `%LOCALAPPDATA%\RocksCellsBrowser\ui-data\vault\`：目次 `index.json`、文字のデータ `items\<id>.json`、画像 `img\<id>-<番号>.png`（画像は C++ だけが書く。名前は決まった形で、png・webp・jpg だけ。UI からは `https://rockscells-vault.example/` で読む）
- ボットの台帳（名前・エージェントの id・右下の並び `dock`）は `%LOCALAPPDATA%\RocksCellsBrowser\ui-data\bots\index.json`、ボットのセルは `ui-data\memocells.json`（`bot` の付いたメモのセル）。セルを外しても、右下から外しても、ボットは台帳に残る。頼む文は保存しない（字数だけ）。依頼と届いた返事は `ui-data\bots\<id>\pending.json`・`log-NNNN.json`、受け取ったファイルは `bot-inbox\` に残る（「ボットの返事を受け取る（第2段）」）
- アプリのセルの台帳（名前・起動するファイル・実行ファイル・アプリ ID・アイコン）は `ui-data\apps.json`。セルの位置は `memocells.json` の `app` です。セルを外しても台帳は残ります（「アプリのセル」）
- 次に起動すると、前回のタブが同じ場所・同じ番号で戻る。前回表示していたタブだけ読み込み、ほかは休眠状態（点線の枠）で並ぶので起動が軽い。クリックすると起きて読み込む

## デモ動画と見取り図を作り直す
機能が増えたら、いまの仕様を見せるデモ動画（約3分）と、画面の見取り図（番号つきの静止画2枚）を作り直せる。

```
powershell -ExecutionPolicy Bypass -File .\tools\demo\record.ps1
```

- 先に `build.ps1` でビルドしておく（`build\Debug\RocksCellsBrowser.exe` を使う。別の exe は `-Exe` で）。Node.js と Python 3 が要る
- テスト用の窓が開いて、約4分自動で操作される（その間は触らない）。そのあと約3分で動画を組み立てる。できたものは `demo\`（`honeycomb-demo.mp4` と PNG 2枚。大きいので git には入れない）
- 毎回まっさらな一時プロフィールで動かすので、ふだんのタブ・Cookie・六角メモには触らない。AI は練習モード（料金なし）。ページと音声はデモ用に作ったもの（`make_site.py`）
- 台本（場面・字幕・見取り図の印）は `tools\demo\drive.mjs`。場面を足すときはここに書く
- しくみ：台本が CDP で本物のマウス・キー入力を送り、`capture.ps1` が窓を約5コマ/秒で撮る → `compose.html` が字幕の帯・カーソル・押したキーを重ねて録画 → `remux.py` が MP4 をふつうの形（長さと目次つき）に直す

ブラウザのデータ（Cookie・キャッシュなど）は `%LOCALAPPDATA%\RocksCellsBrowser\UserData` に保存される。
環境変数 `ROCKSCELLS_DATA_DIR` を指定して起動すると、データの置き場所をそこに変えられる（ふだんのタブや Cookie を汚さずにテストしたいとき用）。このときボットの返事は、本物の置き場（`%LOCALAPPDATA%\RocksCellsRelay\inbox\`）からは取らない。
同じく `ROCKSCELLS_RELAY_DIR` を指定すると、ボットの返事の置き場を `<そのフォルダ>\inbox\` に変えられる（試し用。「ボットの返事を受け取る（第2段）」）。
同じく `HEX_MEMO_HOME` を指定すると、連携する六角メモのデータフォルダをそこに変えられる（六角メモと同じ名前の環境変数。テスト用）。
開発中は、使っている exe を上書きしないよう別のビルド用フォルダ（`build-dev\`）でビルド・テストしてよい（`.gitignore` 済み）。

## 新しいパネルを足すには
1. `ui/src/panels/` にパネルを作る（`preview.ts` のように、HTML の要素を返す関数にしておくと、どこにでも置ける）
2. 置き場所は、左サイドバーの下（`#dock`）・盤面の上（`.overlay`）・右サイドバー（`#panels`）のどれでも使える
3. 右サイドバーに必要な情報は、左から `relay` で送る（C++ は中身を見ずに中継するだけなので、C++ の変更は要らない）
4. 右サイドバーに足した区画は、`ui/src/app/secondary.ts` の `scroll.append(...)` で欄に差し込み（メモの区画の下の区画は `.after(...)` で差し込む）、`mountSectionShelf` に登録すると、たたむ・上のタグの対象になります。登録（`shelf.adopt`・`fold`・`wrap`・`barOn`）は `shelf.finish()` より前に置く。見出しの右クリックの「その他…」は、登録した順に並びます
